## 一、什么是 QuickDock？

**快启坞 QuickDock** 是一款面向 Windows 开发者的桌面效率工具。它的设计灵感来源于：

- **Raycast / Spotlight** — 快捷键唤出，快速搜索和执行
- **VS Code** — 工作空间概念，按项目组织资源

它把这些东西整合到一个界面里：

| 能力 | 内容 |
|------|------|
| **资源管理** | 工作空间 / 场景 / 集合 / 项目四层结构，统一存放目录、网页、命令、应用 |
| **效率工具** | 剪贴板历史、树形笔记、命令面板、待办（含番茄专注）、定时任务、网站监控、**截图工具** |
| **本地开发环境** | 多运行时版本管理与服务启停、Ollama 本地大模型、本地开发站点（自定义域名 + 自动 HTTPS）、HTTP 服务、端口全景 |
| **AI** | 内置 AI 助手（多配置档案 / 五种模式）、DeepSeek Harness Agent 编程入口 |
| **扩展** | 插件市场（一键安装）、自暴露 MCP 服务供外部 AI 客户端调用 |

### 谁适合用？

- **开发者**：管理多个项目，保存常用命令和目录；顺手管理本地运行时与服务
- **运维 / 独立开发者**：本地起 Nginx / 数据库 / 缓存做联调，需要一键启停与端口总览
- **设计师 / 产品经理**：集中存放设计稿链接、规范文档
- **效率控**：习惯用键盘操作电脑、离不开剪贴板历史和截图标注的用户

## 二、快速上手

### 系统要求与安装

**系统要求**

- Windows 10 1809+ 或 Windows 11
- WebView2 Runtime（Windows 自带，无需单独安装）
- 磁盘约 50MB

**安装**

1. 从 [Releases](https://github.com/parieses/quickdock/releases) 下载 `quickdock-amd64-installer.exe`
2. 双击安装。**免管理员权限**，默认装到用户目录 `%LOCALAPPDATA%\Programs\快启坞`
3. 安装完成后启动，任务栏托盘（右下角）出现 QuickDock 图标即成功

> 💡 **建议保持默认安装路径**：自动更新采用「就地替换 exe」，需要对该目录有写权限。若改到
> `C:\Program Files\...`，每次更新都要过 UAC，自动更新会失败（只能手动下载安装包覆盖）。
>
> 也可以直接下载裸 `quickdock-amd64.exe` 当**便携版**用 —— 只要放在当前用户可写的目录即可。

### 启动与基本布局

按 `Ctrl+Space` 唤出主窗口（关闭窗口只是隐藏到托盘，不会退出程序）。左侧为导航栏：

```
┌──────────────┬─────────────────────────────────────┐
│  工作空间 ▾  │                                     │
│ ── 导航 ──   │                                     │
│ 📁 工作空间  │                                     │
│ 📄 笔记      │                                     │
│ ✅ 待办任务  │            主内容区                  │
│ ⏰ 定时任务  │                                     │
│ 📊 网站监控  │                                     │
│ 📋 剪贴板    │                                     │
│ 🖥️ 环境管理  │                                     │
│ 🤖 AI 助手   │                                     │
│ ⌨️ DSH       │                                     │
│ 🧩 插件      │                                     │
│              │                                     │
│ ⚙️ 设置      │                                     │
└──────────────┴─────────────────────────────────────┘
```

- **顶部工作空间切换器**：点 `工作空间 ▾` 切换 / 新建 / 改名 / 删除工作空间
- **导航栏**：`工作空间` 页是三栏资源管理，其余是各功能页；可以**收起为纯图标**（点标题右侧箭头）腾出宽度
- **设置**：固定在导航栏底部

> 💡 在 `工作空间` 页内，右下方还会展开「场景列表」与搜索框，这部分只在工作空间页显示。

### 创建你的第一个工作空间

首次启动会走引导页。也可以随时手动创建：

1. 点击左侧导航栏顶部的 **「工作空间 ▾」**
2. 点击 **「新建工作空间」**
3. 输入名称（如"我的工作"）
4. 点击确定

> 💡 **工作空间是最顶层容器**，把不同性质的工作分开管理（比如一个用于公司项目、一个用于个人项目）。
> 第一个工作空间不能删除，作为兜底。

## 三、核心概念：三层结构

QuickDock 的资源组织方式是一个**四层结构**：

```
工作空间（Workspace）          ← 最顶层，一个独立的工作上下文
  └── 场景（Scene）            ← 按项目或功能分组
       └── 集合（Collection）   ← 按类型或用途归类
            └── 项目（Item）    ← 具体的资源（目录/网页/命令等）
```

### 工作空间（Workspace）

每个工作空间是一个**完全独立的环境**。你可以创建多个：

- `工作` — 存放工作相关的所有资源
- `个人项目` — 存放个人项目、学习资料
- `博客维护` — 专门管理博客相关的内容

**切换工作空间**：点击左侧导航栏顶部的 `工作空间 ▾`，在下拉菜单中切换。

### 场景（Scene）

场景是**工作空间下的视图分组**，类似浏览器的标签页：

- `日常开发` — 开发中最常用的资源和工具
- `项目管理` — 项目文档、甘特图链接、会议记录
- `部署运维` — 服务器地址、部署指南、监控地址

**管理场景**：在 `工作空间` 页的侧栏点击 `+` 新建场景；场景支持标签、图标、颜色，可拖拽排序。

### 集合（Collection）

集合是**更细粒度的分类**，把同一类资源放到一起：

- `常用工具` — 编辑器、终端、设计软件
- `项目文档` — PRD、设计稿、API 文档链接
- `快捷命令` — git 提交流程、构建脚本、数据库连接

**创建集合**：选中场景后，在中间列表点击 `+`，填写名称并选择集合类型。集合支持多种打开策略。

### 项目（Item）

项目是**最具体的资源**，支持 6 种类型：

| 类型 | 说明 | 示例值 |
|------|------|--------|
| `directory` 目录 | 用系统 / 终端打开 | `D:\project\quickdock` |
| `file` 文件 | 用系统默认程序打开 | `D:\docs\readme.md` |
| `url` 网页 | 在浏览器中打开 | `https://github.com` |
| `command` 命令 | 在终端中执行 | `git status` |
| `app` 应用 | 启动应用程序 | `C:\Windows\System32\notepad.exe` |
| `quicklink` 快速链接 | 带参数的快捷方式 | 支持 `{query}` 占位符 |

**占位符替换**：项目的值（命令、网址、快速链接）支持以下内置变量，打开或执行时自动替换：

| 占位符 | 替换为 |
|--------|--------|
| `{date}` | 当前日期，如 `2026-09-20` |
| `{time}` | 当前时间，如 `14:30:00` |
| `{username}` | Windows 用户名 |
| `{clipboard}` | 当前剪贴板内容 |
| `{query}` | 运行时弹窗让你输入的内容（快速链接专用） |

> 🔗 **快速链接的高级用法**：在值中使用 `{query}` 占位符，选中该链接时会提示输入内容并自动替换。
> 例如一个 Google 搜索链接：`https://www.google.com/search?q={query}`

整个层级都支持拖拽排序和全文搜索。

### 实战：搭建一个开发工作空间

#### 1. 创建"后端开发"工作空间

- 点击导航栏顶部 `工作空间 ▾` → 新建工作空间 → 起名：`后端开发`

#### 2. 添加场景

- 添加场景 `日常开发`
- 添加场景 `项目文档`

#### 3. 在"日常开发"场景下添加集合

- `常用工具`（类型：应用集合）
- `项目目录`（类型：目录集合）
- `常用命令`（类型：命令集合）

#### 4. 在集合中添加项目

- 在"常用工具"下添加：
  - VS Code（类型：app，路径：`C:\Users\你\AppData\Local\Programs\Microsoft VS Code\Code.exe`）
  - Chrome（类型：app）
- 在"项目目录"下添加：
  - 后端项目（类型：directory，路径：`D:\project\quickdock`）
- 在"常用命令"下添加：
  - Git 状态（类型：command，值：`git status`）
  - 构建项目（类型：command，值：`go build ./...`）

> 💡 以后直接双击项目就能一键跳转目录、打开应用或执行命令；按 `Ctrl+K` 也能搜到它们。

## 四、全局热键一览

QuickDock 的精髓在于**键盘驱动**。默认全局热键：

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl + Space` | 切换主窗口 | 显示/隐藏主界面 |
| `` Ctrl + ` `` | 切换剪贴板窗口 | 显示/隐藏剪贴板浮动窗口 |
| `Ctrl + K` | 切换命令面板 | 显示/隐藏命令面板 |
| `Ctrl + Shift + N` | 切换快捷笔记 | 显示/隐藏笔记浮动窗口 |
| `F1` | 区域截图 | 唤起全屏覆盖层框选截图（被占用时自动回退 `Ctrl+Shift+A`） |

> 所有热键都可以在 **设置 → 热键** 中自定义。捕获新热键时会自动暂停全局监听，避免与其他软件抢键。

## 五、各功能模块详解

### 1. 命令面板（Command Palette）

命令面板是 QuickDock 的**中枢神经**，按 `Ctrl+K` 随时唤出。

#### 能搜什么？

- 工作空间、场景、集合、项目的名称
- **笔记**（按名称与内容搜索）
- **环境运行时**（快速跳转到某个运行时）
- 系统命令（锁屏、关机、区域截图等）
- 插件命令
- 最近使用 / 最常使用的记录

#### 高级功能

- **内置计算器**：直接输入算式或换算表达式，如 `1024MB = ?GB`、`100kg = ?lb`
- **URL 智能建议**：复制链接后打开命令面板，自动提示打开或保存
- **多选批量操作**：按住 `Ctrl` 点击多选，按 `Enter` 批量打开
- **`{query}` 占位符**：选中含占位符的项目后输入内容

#### 使用技巧

```
# 查找项目
输入 "展开" → 搜索所有包含关键词的资源

# 快速换算
输入 "1024MB = ?GB" → 直接显示换算结果，回车复制

# 批量打开网页
按住 Ctrl 点击多个网页链接 → Enter 全部打开
```

---

### 2. 剪贴板历史（Clipboard History）

按 `` Ctrl+` `` 唤出剪贴板浮动窗口（失焦自动隐藏），自动记录你复制过的内容。

#### 功能

- **文本**：自动记录所有复制的文字
- **图片**：复制图片后自动保存到历史
- **文件**：记录复制过的文件路径
- **搜索**：在剪贴板历史中搜索
- **固定**：常用内容点击星标固定，**清空时会被保留**
- **复制**：点击任一记录即复制回剪贴板
- **批量删除 / 立即清空**

#### 数据保留

剪贴板历史默认保留最近 **30 天**（可在设置中调整），超过后自动清理；被固定的条目不受影响。

---

### 3. 笔记（Notes）

按 `Ctrl+Shift+N` 唤出**快捷笔记**浮动窗口，随时记录灵感，失焦自动隐藏。

- **自动保存**：停止输入 500ms 后自动保存，无需手动操作
- **本地存储**：笔记数据存在本机数据库，不经过任何云端

导航栏的 **`笔记`** 页是**完整笔记库**，比浮窗更强：

- **树形结构**：文件夹 + Markdown 文档，可任意多层级嵌套
- **搜索**：按名称 / 内容 / 标签搜索
- **管理**：重命名、移动、删除（删除文件夹会连带下级）
- **旧数据兼容**：历史版本的快捷笔记会自动出现在笔记树的根级

> 💡 早期版本里还有一个独立的「文本片段」功能，现已整体并入笔记体系。

---

### 4. 待办任务（Todos）

轻量级的任务管理工具。

#### 功能

- **列表视图 + 看板视图**：看板为三列（待办 / 进行中 / 已完成），可拖拽管理
- **状态循环**：待办 → 进行中 → 已完成
- **子任务**：在任务下添加子任务（单层级 checklist）
- **标签分类**：给任务打标签，按标签筛选
- **重复待办**：每日 / 每周 / 每月重复
- **到期提醒**：到期后发系统通知
- **🍅 番茄专注**：在待办页启动专注倒计时，结束时发系统通知，可同时推送 Webhook

#### 使用场景

- 开发 TODO 清单：`添加用户登录功能` → `进行中` → `完成`
- 日常工作：每日例行任务设置重复，到点自动出现
- 项目追踪：用标签区分 `前端` / `后端` / `Bugs`
- 专注工作：给当前任务开一个 25 分钟番茄钟

### 5. 定时任务（Schedules）

让 QuickDock 在指定时间**自动执行**某些操作。

#### 动作类型（5 种）

| 动作 | 说明 |
|------|------|
| 打开软件 | 定时启动指定应用程序 |
| 打开目录 | 定时在资源管理器中打开某个文件夹 |
| 打开网页 | 定时在浏览器中打开网址 |
| 执行命令 | 定时在终端中执行命令（可指定工作目录） |
| HTTP 请求 | 定时向指定 URL 发起请求（可配方法 / 请求头 / 请求体） |

#### 调度方式（4 种）

| 调度 | 说明 |
|------|------|
| 一次性 | 指定时刻执行一次 |
| 固定间隔 | 每隔 N 秒 / 分钟 / 小时 / 天执行 |
| 每天 | 每天固定时刻执行 |
| 每周 | 每周指定星期几的固定时刻执行 |

任务执行后会发系统通知；也可以随时点 **「立即运行」** 手动触发一次。任务支持机器人通知配置。

#### 实战例子

```
每天早上 9:00   → 打开飞书 / 钉钉
每个周一 10:00  → 执行 git pull 拉取最新代码
每小时一次      → 发起一次 HTTP 请求体检接口
每天 17:00      → 打开日报页面
```

---

### 6. 网站监控（Monitors）

监控网站或 API 的可用性，出问题时第一时间通知你。

#### 功能

- **HTTP 探测**：定时检查 URL 是否正常返回，支持 GET / HEAD / POST，可自定义检测间隔
- **状态码验证**：可指定期望的 HTTP 状态码（如 200、301）
- **SSL 证书到期预警**：自动检测证书到期时间，提前 X 天告警
- **内容匹配**：检查页面是否包含（或不包含）指定关键字或正则表达式
- **在线率统计与检测日志**
- **响应时间趋势图**：24 小时 / 7 天 / 全部
- **多渠道通知**：状态翻转时发桌面通知，并可推送到钉钉 / 企业微信 / 飞书 / Server酱 / PushPlus / Telegram

#### 通知内容示例

```
🔔 QuickDock 网站监控告警
监控目标: https://example.com
状态: DOWN (期望 200，实际 503)
时间: 2026-09-20 14:30:00
```

### 7. 截图工具（Screenshot）

内置 Snipaste 形态的截图工具，按 **`F1`** 唤起全屏覆盖层，**框选 → 标注 → 复制 / 保存 / 贴图**一条链路走完。

#### 基本流程

1. 按 `F1`，屏幕进入可框选状态
2. **拖拽框选**任意区域；或**把鼠标移到某个窗口上单击**直接选中整个窗口
3. 松手后，选区下方**原地浮出工具条**
4. 标注完成后：`Enter` / `Ctrl+C` 复制，`Ctrl+S` 保存，或点「贴图」钉在屏幕上

#### 工具条能力

| 分区 | 内容 |
|------|------|
| 工具 | 矩形 / 椭圆 / 箭头 / 直线 / 马赛克 / 文字 |
| 颜色 | 9 色调色板 |
| 线宽 | 4 档 |
| 字号 | 6 档（与线宽独立） |
| 撤销 / 重做 | 任意步骤可回退 |
| 输出 | 复制 / 保存 / 贴图 / 关闭 |

#### 好用的细节

### 8. 环境管理（Environments）

这是 QuickDock 里最"重"的一块：**多运行时版本管理器**，一键安装 / 切换 / 启停，多版本共存于用户目录，**不写注册表、不申请管理员权限、不污染系统 PATH**。

#### 运行时按职责分组

| 分组 | 包含 |
|------|------|
| **语言** | Node.js、Go、PHP、Python、Bun、Erlang |
| **网络服务** | Nginx、Caddy、Apache、Traefik、FTP |
| **数据库** | MySQL、MariaDB、PostgreSQL、MongoDB |
| **中间件** | Redis、Memcached、MinIO、RabbitMQ |
| **AI 服务** | Ollama（本地大模型，含模型管理） |
| **开发工具** | Git、Composer、FFmpeg、Mailpit、frpc、GitHub CLI、mkcert |
| **内置工具** | HTTP 服务、端口全景、站点 |

#### 基本用法

1. 点击运行时名称 → 自动加载**版本列表**
2. 选一个版本安装（下载 → 解压 → 安装全程异步，进度实时显示）
3. 装好后可**切换当前激活版本**（写入环境变量，多版本共存）
4. 服务型运行时（数据库、缓存、Web 服务器等）可**启动 / 停止 / 重启**，状态列实时显示 PID、端口与健康状态

#### 服务型运行时的额外入口

- **编辑配置**：如 `Caddyfile` / `nginx.conf` / `redis.conf` / `php.ini` / `traefik.yml`
  - Nginx、Apache、Caddy 支持**启动前配置校验**，校验失败会阻止启动（避免带着错误配置起不来）
- **查看日志**：实时滚动读取进程日志尾部
- **打开控制台**：运行时带 Web UI 时一键打开（MinIO、Mailpit、Traefik、RabbitMQ 等）
- **端口全景**：点顶栏按钮，在弹窗里汇总所有运行中服务的运行时 / 版本 / 端口 / 控制台入口

#### Ollama 本地大模型

- **单版本语义**：程序目录固定 `runtime/ollama/`，不做多版本并存（单份约 1.4 GB，且独占 11434、模型库全局共享，多版本是纯成本）
- **只提示不自动更新**：检测到新版本时出现提示条，由你点「更新」触发；失败不影响当前版本
- **模型管理**：直接读取本机 Ollama，可查看已装模型与体积、拉取模型（流式进度）、删除模型
- **模型库共享**：默认与系统安装版、命令行 `ollama` 共用 `~/.ollama/models`，避免重下数十 GB
- **卸载只删程序**：删除 `runtime/ollama/`，绝不触碰模型目录

#### 站点（本地开发站点）

给本地项目**一键绑定自定义域名 + 自动 HTTPS**，入口在「内置工具」组。

- 对外服务交给已装的 **Nginx / Caddy**（HTTPS 443，HTTP 80 跳转）；**QuickDock 自己不监听任何端口**
- 需要先装好 Nginx 或 Caddy，否则站点配置片段会落盘但没人加载
- QuickDock 负责：签发一张覆盖全部启用域名的证书、写入 hosts 的标记区块、生成站点配置片段并触发热重载
- **绝不自动改写你的 `nginx.conf` / `Caddyfile`** —— 片段写在配置同级的 `quickdock-sites/` 目录，需要你在主配置里引入一次
- 提供 Laravel / ThinkPHP / Yii / Symfony / WordPress 等项目类型模板；纯静态站点不生成 PHP 段

#### HTTP 服务

把某个本地目录临时挂成一个 HTTP 服务，适合给同事临时分享静态文件。

### 9. AI 助手（AI）

内置 AI 对话，支持**多种服务商**与**流式输出**。

#### 先配置

1. 进入 **设置 → AI**
2. 添加一个**配置档案**，选择服务商：OpenAI / DeepSeek / Kimi / 通义千问 / Ollama / Azure OpenAI / 自定义兼容接口
3. 填写 API Key 与模型名，点 **「测试连接」** 验证可用
4. 保存后回到 **`AI 助手`** 页开始对话

> 🔒 API Key 在 Windows 下使用 DPAPI 加密存储，前端不接触密文。

#### 五种对话模式

| 模式 | 用途 |
|------|------|
| 聊天 | 通用助手 |
| 解释代码 | 说明代码功能、关键逻辑、边界情况与改进建议 |
| 翻译 | 中英互译 |
| 总结 | 把长内容提炼成要点 |
| 使用教程 | 问 QuickDock 自己的功能怎么用，会给出具体入口与分步操作 |

模式只是切换 system prompt，**你仍然需要输入你的问题**（例如在「使用教程」模式下问"怎么装 Node.js"）。
模式 prompt 之上还可以叠加你自己的自定义 System Prompt。

#### 其他能力

- **流式输出**：本地 HTTP 流式服务，token 到达即显示
- **思考过程折叠**：模型的 reasoning 内容默认收起，需要时展开
- **会话管理**：多会话、标题自动生成、重新生成标题、清空上下文、删除会话
- **参数可调**：Temperature / MaxTokens / TopP / FrequencyPenalty / PresencePenalty
- **Token 用量统计**：每次对话记录 prompt 与 completion token 数

### 10. DeepSeek Harness（DSH）

内嵌 [DeepSeek Harness](https://github.com/deepseek-ai/dsh)，是比 AI 助手更"重"的 **Agent 编程入口**（工具 / 文件 / 终端 / 会话），两者互补：

1. 在设置页的 DSH 入口点「装填环境」：自动检测 node / npx / dsh，缺失时下载便携 Node 并安装 `@deepseek-ai/dsh`
2. 安装过程有实时日志（下载 / 解压 / npm 安装逐行推送）
3. 装好后从导航栏 `DSH` 进入，用原生窗口承载官方 Web 界面
4. 服务**后台常驻**：关窗不停，下次点击秒开；真正停止在设置里手动操作

设置页还可以直接安装 DSH 插件。数据复用官方 `~/.dsh` 目录。

## 六、数据安全与数据位置

### 快照备份

QuickDock 支持创建和恢复完整的数据快照：

1. 进入 **设置 → 快照**
2. 点击 **创建快照**，所有数据（工作空间、场景、集合、项目、笔记、待办、设置等）保存为一个 JSON 文件
3. 需要恢复时，点击 **从快照恢复**
4. 也可以删除不再需要的快照

> 💡 建议在重大修改前创建一个快照，作为安全网。

### WebDAV 云同步

如果你有自己的 WebDAV 网盘（如 NextCloud、Synology），可以配置云同步：

1. 进入 **设置 → 同步**
2. 填写服务器地址、用户名、密码
3. 测试连接，验证配置正确
4. 执行同步，数据上传到你的云端（保留多版本）
5. 另一台电脑上同样配置后，可从云端恢复

### 数据存放位置

| 路径 | 内容 |
|------|------|
| `~/.quickdock/quickdock.db` | SQLite 数据库（工作空间 / 项目 / 笔记 / 待办 / 定时 / 监控 / AI 会话等） |
| `~/.quickdock/images/` | 剪贴板图片 |
| `~/.quickdock/plugins/` | 已安装的插件 |
| `~/.quickdock/runtime/` | 便携运行时（Node / DSH 等） |
| `~/.quickdock/logs/` | 运行日志（`quickdock-YYYY-MM-DD.log`） |
| `%APPDATA%/QuickDock/` | 应用配置与运行时安装目录 |
| `~/.ollama/models` | Ollama 模型库（与系统安装版共用，卸载 QuickDock 不会删） |

> `~` 即 `C:\Users\<你的用户名>`。

## 七、常见问题

### Q: QuickDock 是否免费？

目前免费使用，MIT 协议开源。

### Q: 需要管理员权限吗？

安装和日常使用**都不需要**。插件、运行时、数据全部落在用户目录。唯一例外是某些需要提权的系统级操作（如把站点域名写入 `hosts` 时会先写可写副本再由提权子进程落盘）。

### Q: 数据存在哪里？安全吗？

所有数据存储在本地 SQLite 数据库 `~/.quickdock/quickdock.db` 中，**不上传任何云端**（除非你主动配置了 WebDAV）。剪贴板中的图片存储在 `~/.quickdock/images/`。AI 的 API Key 经 Windows DPAPI 加密。

### Q: 如何完全退出 QuickDock？

右键托盘图标 → **退出**。**关闭主窗口只会隐藏到托盘，不会退出程序**（浮动窗口同理）。

### Q: 如何备份数据？

两种方式：① 在设置中创建快照（推荐定期做）；② 配置 WebDAV 云同步（跨设备）。

### Q: 更换电脑后如何迁移数据？

1. 旧电脑：创建快照 → 导出快照文件
2. 新电脑：安装 QuickDock → 设置 → 快照 → 从快照恢复

或者直接配置 WebDAV，一键同步。注意**运行时不会跟着迁移**，需要在新机器上重新安装。

### Q: 笔记的内容存在哪里？

存在本地数据库的 `notes` 表里，以「文件夹 + 文档」的树形结构组织，与工作空间数据一同被快照 / 同步覆盖。

### Q: 剪贴板历史存多少条？

默认保留 **30 天**（可在设置中调整）。超过保留期限且未被固定（★）的条目会被自动清理。

### Q: 装了这么多运行时，会不会很占空间？

运行时装多少占多少，都放在 `~/.quickdock/runtime/` 下，卸载对应版本即释放。Ollama 比较大（约 1.4 GB），但它**复用系统模型库**，不会重复下载模型。

### Q: 站点功能为什么配好域名却打不开？

最常见两个原因：① **没装 / 没启动 Nginx 或 Caddy**（站点由它们提供服务，QuickDock 自己不开端口）；② **主配置里没有引入 `quickdock-sites/` 目录**。另外首次可能需要在主配置里手工加一次引入语句。

### Q: 截图按 F1 没反应？

`F1` 可能被前台程序（如 IDE 帮助键）占用。QuickDock 会自动回退到 `Ctrl+Shift+A` 并在日志中提示，也可以到设置里改成别的热键。
