01

Three panes, one working day

Navigation on the left, collections in the middle, items on the right. The tree has four levels, and an item can be a folder, a file, a URL, a command, an app, or a shortcut with arguments.

Resources

Where things live is up to you

Workspaces separate contexts, scenarios are different slices of the same resources, collections group by purpose. Every level can be dragged into order.

  • Four levels: workspace → scenario → collection → item
  • FTS5 full-text search; matches Chinese and English alike
  • Commands and URLs accept {date} {time} {clipboard}, expanded on open
Runtimes

29 runtimes, all under your user folder

Languages, databases, middleware, web servers, dev tools — as many versions as you want. Switching changes one environment variable: no registry writes, no system PATH.

  • Install progress streamed line by line; mirrors switchable with fallback
  • Nginx, Apache and Caddy run their *-t check before starting
  • Service logs, web console and port overview on one page
Plugins

Plugins run sandboxed, permissions are declared

Three runtimes: plain front-end, embedded JS sandbox, separate process. Whatever a plugin needs has to be declared in plugin.json; anything undeclared is refused.

  • 34 host APIs covering files, network, clipboard, processes and crypto
  • Native plugins are statically audited at install time; manifest mismatches are flagged
  • Official plugins install and update from the built-in marketplace
02

The dozen tools you'd otherwise open separately

None of them is remarkable on its own. The difference is that they share one window and one set of hotkeys, so taking a screenshot or glancing at a log doesn't mean launching another app.

Command palette Ctrl K
Searches projects, notes, todos, apps, files and plugin commands at once, grouped by source; file results preview inside the panel. Paste a URL and it offers to save it as a project.
Clipboard history Ctrl `
Text, images and files are all recorded. Images and files are types of their own; URLs, emails, JSON and code are classified on write, so a tag reaches the whole history.
Screenshot F1
A layered native window acts as the overlay: selecting, annotating, color picking, numbered markers, copying and pinning all happen inside it, no second window.
Window tiling Ctrl Alt W
15 snap hotkeys plus a 3×3 overlay you click once. It doesn't take over Win + arrow keys.
Quick notes Ctrl Alt N
A tree of Markdown notes, autosaved, hidden as soon as it loses focus. Ask the AI from the same float window.
Todos
List and kanban views, subtasks, tags, repeat rules, due reminders, plus a pomodoro timer.
Site monitor
Four probe types — HTTP / TCP port / local process / custom command — with status codes, response time and SSL expiry. Pushes to the desktop or a webhook when a target flips state.
Scheduled tasks
Open an app, folder or URL, run a command, send an HTTP request. Once, every N minutes, daily, weekly.
SSH terminal Ctrl Alt S
Tabbed sessions, SFTP, host key trust, batch execution across hosts. An AI sidebar docks on the right.
Git panel
SourceTree-style: branches, tags and remotes, stashes, file history and blame, amend, cherry-pick, branch comparison and side-by-side diff.
File search
A dedicated page backed by Everything: install guidance when it is missing, one-click start when it is not running; queries take Everything syntax directly, results sort, multi-select for copying paths, and files preview on the right.
Downloader
aria2 under the hood: links, magnets, torrents and Metalink in one list, with status tabs, batch actions, a seven-tab detail dialog, speed charts and a pre-flight space check. Per-task save folders, file-named sub-folders, a disk guard and cross-machine resume import all live in settings.
Log tail
tail -f on any local file. Realigns when the file rotates or is rewritten in place; pausable, with highlight filters.
Dashboard
A date bar with the lunar date, solar terms and the day's traditional do's and don'ts, plus local weather. Eight cards hold recent items, the file shelf, todos, mail verification codes, ports, resident services, Git and AI usage — clicking a row lands on that item. City search accepts provinces, abbreviations and both languages, resolving a province to its capital; mail cards open the original message.
Notification center
Monitor outages, scheduled task results, mail verification codes and finished AI answers land in one bell. Click through to the monitor, the task or the conversation.
Data directory migration
Move the whole data directory, installed runtimes included, to another drive; environment variables are rewritten. Useful when C: runs out.
Local dev sites
Bind a custom domain to a project and issue an HTTPS certificate automatically. Listens on no port of its own.
WebDAV sync
Full JSON export and restore, versioned snapshots, any WebDAV server.

How versions install

Mirrors are switchable, and the address accepts {version} {os} {arch} placeholders. When one source fails the next is tried, with progress streamed back live.

How services are managed

Start, stop and restart from the list. Save a config and services like Nginx validate before reloading — a syntax error stops there instead of taking down a running service.

Does it touch the system

No registry writes, no changes to system PATH, no admin prompt. Delete the folder and it is gone, with nothing left behind.

04

Configure a model once, use it in four places

The chat page, the SSH sidebar, clipboard entries and the notes window share one model profile.

Models and chat

OpenAI, DeepSeek, Kimi, Qwen, Ollama, Azure, and any compatible endpoint.

  • Enter the base URL and key, then pull that endpoint's model list in one click instead of copying names by hand
  • SSE streaming, with the reasoning trace collapsed by default
  • Math renders through KaTeX, diagrams through Mermaid, code blocks get highlighting; right-click a diagram or formula to copy it as an image
  • Switch to another page while an answer is generating; it keeps going and is waiting where you left it
  • Usage stats cover every entry point, split by model and surface, and are labelled as an estimate rather than a bill
  • API keys are encrypted with Windows DPAPI; the front end never sees the ciphertext

AI in the terminal

The SSH sidebar turns what you're looking at into commands you can run.

  • Select terminal output, right-click, ask — the selection alone becomes the context
  • The screen is attached only when you mention it; otherwise it isn't sent, which saves tokens and avoids misleading the model
  • On production hosts the default is read-only probing; write commands must state their blast radius
  • rm -rf, mkfs and DROP TABLE get a fill-in button only, never a run button
  • Running on production asks twice; fill-in never sends a newline
  • Switching sessions clears the context, so machine A's screen never follows you to machine B

Local capabilities for agents

A built-in MCP server at http://127.0.0.1:9230/mcp.

  • Tools are split into three permission tiers; read-only and low-risk writes are on by default
  • Read-only covers runtime status, project search, todos, notes, clipboard, ports, logs and crash records
  • Low-risk writes start and stop services, open projects, create todos and notes
  • Killing processes and running system commands have to be enabled separately in the runtimes page
  • Starts and stops with the main process; gone when the app quits

DeepSeek Harness

A complete agent coding surface in a native window: tools, files, terminal, sessions.

  • Detects node, npx and dsh and installs whatever is missing, a portable Node included
  • Runs in its own native window; closing the window leaves the service running, and reopening returns to it
  • Fixed port 3080, falling back to a random port only when an unrelated process holds it
  • Every step — download, extract, npm install — is logged
05

What changed recently

Newest first, expand for detail. Older versions live in GitHub Releases.

The password vault is here: web logins autofill, SSH passwords get a home
  • A new password vault: web logins, SSH, databases, Git, WebDAV and API keys in one place. AES-256-GCM at rest, with the key itself wrapped by the system DPAPI. Stored on this machine only and excluded from WebDAV backups — which is exactly what keeps passwords off the wire. Copied passwords clear from the clipboard after 30 seconds, and the in-memory key is wiped when you lock the app and rebuilt silently on unlock.
  • With the Chrome / Edge extension, web forms fill themselves: a suggestion strip appears next to the password field listing only entries that match the current domain, so the whole vault never lands on someone else's screen. Filled values submit correctly on React / Vue sites too. After login it offers to save, new passwords save automatically and changed ones still ask for confirmation, tracked per site so two different logins can't overwrite each other. One switch in the vault page controls the extension; turning it off stops the local listener immediately.
  • SSH hosts no longer require a password up front: you are asked at connect time, and the answer goes into the vault and is remembered for that host. If the password changed, entering the new one overwrites both the host and the vault entry. The host form also has a "fill from vault" button.
  • Note previews and code panes can finally be selected and copied. The app disables selection globally (to keep UI text from being dragged along), and that rule was inherited into the note pages — the preview could not even form a selection, and the code pane showed a highlight while Ctrl+C produced nothing. Selection and active-line colors were rebuilt too: the active line used to be opaque and painted over the selection on the cursor's line, which looked like "one line goes missing".
  • Knowledge base: after pressing Stop, rebuild requests were silently dropped — the queue now recovers. Switching embedding models now gives accurate semantic search: vectors from two different models used to be mixed into one similarity space, and the symptom was "results look fine, just wrong", which is far harder to spot than an error. A malformed PDF can no longer stall indexing.
  • "Go to environments" on the downloader and Git pages now lands on the right runtime. It used to stop at the default node entry, leaving you to scroll through thirty-odd runtimes yourself.
v0.0.48 2026-11-11 PDF search in the knowledge base works again; embeddings can use their own provider
  • Fixed "search returns nothing" after importing a PDF: WPS / Word exports place every Chinese character and every digit as a separate text block, so the "insert a space when the gap exceeds the font size" heuristic fired on every single gap and turned a page into "項 目 立 項" or "6 0 分". The index stored those space-riddled strings while queries match three-character windows, so nothing ever hit. The file was indexed fine — the text was broken. Spaces are no longer inserted between CJK characters, digits and percent signs (spaces between CJK and Latin text are kept), and already-indexed documents recover with one rebuild.
  • Search now understands multi-word and full-sentence queries: the whole query used to be wrapped in one phrase, requiring a verbatim contiguous match — multi-word queries with spaces failed outright, and asking a natural-language question (which Q&A passes straight through) almost always came back empty. Queries are now split into terms, Chinese terms match on three-character windows joined by OR, terms are joined by AND, and when the strict pass finds nothing it falls back to OR.
  • Mixed tokens such as "60分", "80分" and "70%" used to be split by script, each fragment dropped for being under three characters, leaving an empty query — now the whole token is used as a fallback.
  • Knowledge base settings actually persist now: the app_state key whitelist was missing kb_settings, so saving failed with invalid app_state key and reading silently fell back to defaults — the embedding model typed into the settings dialog was never used and rebuilds never produced vectors, without leaving a trace.
  • Embeddings can use a dedicated provider: a separate endpoint and key can be set for the embedding model, falling back to the active AI profile when left empty. DeepSeek and several relays only serve chat models without an /embeddings endpoint, so pointing the knowledge base at a provider like SiliconFlow's BAAI/bge-m3 is now enough. The key is masked on every read.
  • With an embedding model configured, Q&A upgrades from keyword-only to keyword + semantic retrieval fused with RRF, which noticeably improves hits for conversational questions.
v0.0.47 2026-11-11 Mail source view, runtime info cards, and a round of fixes
  • Mail codes now open the original message: HTML is rendered with the card's own styles, no remote assets and no scripts. Both MaxMind security-alert templates are recognized too, and password-change / new-location sign-in alerts are flagged separately and pushed to the notification center. Multi-account template quirks and connection error messages were tidied up along the way.
  • The "?" next to each runtime in Environment grew from a single sentence into an info card: group, what you can actually do on this page, a first-use tip, live status (installed versions / managed service / always-on switch / console port), plus website, docs and source links. The popover measures its real height to pick a side and scrolls internally when the content is long.
  • Weather city search no longer returns a pile of same-named villages. Typing "Henan" used to surface places literally called Henan in Heilongjiang, Zhejiang, Beijing, North Korea and Sichuan; provinces, abbreviations and both Chinese / English input now resolve to the provincial capital. Results are ranked by population and administrative level, with airports, hamlets and duplicate multilingual aliases filtered out. Cities with patchy Chinese indexing such as Haikou and Taipei are fixed as well.
  • Thoughts and tool calls in the AI assistant are now collapsed by default, including while streaming. The summary lines show a live character count / call count as progress, and only a click expands the content, so a long chain of thought or half a dozen tool calls no longer pushes the answer off screen.
  • Fixed "click any nav item and the whole content area goes blank": the dashboard template had become a fragment root, which collided with the out-in page transition. The leave hook never fired, so the placeholder stayed forever. The dialog is back inside the single root, and the page registry now spells out the single-root rule.
  • The first-use guide is easier to find: both Settings -> About and the workspace empty-state guide link to it, with the URL kept in one place in the code.
  • Reliability: an aria2 download directory on a removed external drive no longer traps startup in an endless self-heal loop, and the same portable / system install no longer shows up as two versions. Clipboard probe failure logging, command-palette FTS5 queries, the SFTP permissions dialog, and a few note / download-settings interactions were fixed too.
v0.0.46 2026-11-10 Startup lock, and no more white flash when a panel opens
  • Startup lock: lock the interface when you step away. The main window and every detached window collapse to one unlock box, and panel hotkeys bring up the main window with a hint instead. Everything behind keeps running — monitors, scheduled tasks, mail codes, weather, the clipboard listener, SSH sessions, the MCP listener. MCP tool calls are refused wholesale while locked (handing the whole database to any local process would defeat the point); window tiling Ctrl+Alt+W and screenshots F1 stay allowed.
  • The password itself: bcrypt, then DPAPI, then app_state — a table deliberately left out of WebDAV backups, so the password never travels with a sync and restoring elsewhere means setting it again. A one-time recovery code is shown when you set it (only its hash is stored); use it to clear the password if you forget. Five wrong tries start a backoff that doubles up to five minutes, timed in the backend.
  • Unlocks on the last keystroke: the length is recorded when the password is set or changed, and the box submits as soon as that many characters are in — no Enter needed. Counted in characters, so emoji work; IME composition is skipped so pinyin can't trigger it mid-word. Passwords set before this release pick the length up on their first successful unlock.
  • The white flash when a panel opens is gone. When Wails hides a window it also makes the WebView2 controller invisible, which releases the GPU surface; the first frame after showing again is empty, and it is drawn inside the WebView2 child window, above our client area — window background and DWM material cannot cover it (both themes flash the same pure white). Windows are now moved off-screen before showing and moved back 60ms later. The material rewrite on a single wake-up also went from two passes to one.
  • Performance: the notes panel's CodeMirror core loads on demand, saving about 300KB on the main window's first paint; log tailing gets an 8MB budget and drops an O(n²) prepend, so multi-hundred-megabyte runtime logs no longer load whole; app_state reads get an in-process cache, cutting three DB round-trips per clipboard copy; the dashboard heat grid and two search highlighters moved into computed caches.

Does it need admin rights?

No. The installer puts the program in %LOCALAPPDATA%\Programs\快启坞, and runtimes and data stay in your user folder — no registry writes, no UAC prompt. For the same reason, installing by hand into C:\Program Files breaks auto-update, because there is no write permission and you'd have to overwrite it manually.

Where is my data, and does it get uploaded?

In ~/.quickdock by default: the database, clipboard images, plugins and logs. Nothing syncs in the background; network requests only happen when you configure WebDAV or call an AI endpoint. If space runs short, move the whole directory to another drive under Settings → Storage & Sync.

Does uninstalling delete my data?

No. Uninstalling removes the program and its registry entry; ~/.quickdock stays. Reinstall and everything is where you left it. Delete the folder yourself once you're sure you don't need it.

Is macOS supported?

Each release ships darwin arm64 and amd64 builds, but development and testing happen on Windows, so coverage on macOS is incomplete — please file an issue if you hit something. There is no Developer ID signature yet, so the first launch has to be allowed in System Settings.
