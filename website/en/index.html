01

Three panes, one working day

Navigation on the left, collections in the middle, items on the right. The tree has four levels, and an item can be a folder, a file, a URL, a command, an app, or a shortcut with arguments.

Resources

Where things live is up to you

Workspaces separate contexts, scenarios are different slices of the same resources, collections group by purpose. Every level can be dragged into order.

  • Four levels: workspace → scenario → collection → item
  • FTS5 full-text search; matches Chinese and English alike
  • Commands and URLs accept {date} {time} {clipboard}, expanded on open
Runtimes

28 runtimes, all under your user folder

Languages, databases, middleware, web servers, dev tools — as many versions as you want. Switching changes one environment variable: no registry writes, no system PATH.

  • Install progress streamed line by line; mirrors switchable with fallback
  • Nginx, Apache and Caddy run their *-t check before starting
  • Service logs, web console and port overview on one page
Plugins

Plugins run sandboxed, permissions are declared

Three runtimes: plain front-end, embedded JS sandbox, separate process. Whatever a plugin needs has to be declared in plugin.json; anything undeclared is refused.

  • 34 host APIs covering files, network, clipboard, processes and crypto
  • Native plugins are statically audited at install time; manifest mismatches are flagged
  • Official plugins install and update from the built-in marketplace
02

The dozen tools you'd otherwise open separately

None of them is remarkable on its own. The difference is that they share one window and one set of hotkeys, so taking a screenshot or glancing at a log doesn't mean launching another app.

Command palette Ctrl K
Searches projects, notes, todos, apps, files and plugin commands at once, grouped by source. Paste a URL and it offers to save it as a project.
Clipboard history Ctrl `
Text, images and files are all recorded. Images and files are types of their own; URLs, emails, JSON and code are classified on write, so a tag reaches the whole history.
Screenshot F1
A layered native window acts as the overlay: selecting, annotating, copying and pinning all happen inside it, no second window.
Window tiling Ctrl Alt W
15 snap hotkeys plus a 3×3 overlay you click once. It doesn't take over Win + arrow keys.
Quick notes Ctrl Alt N
A tree of Markdown notes, autosaved, hidden as soon as it loses focus. Ask the AI from the same float window.
Todos
List and kanban views, subtasks, tags, repeat rules, due reminders, plus a pomodoro timer.
Site monitor
Status codes, response time, SSL expiry, keyword matching. Pushes to the desktop or a webhook when a target flips state.
Scheduled tasks
Open an app, folder or URL, run a command, send an HTTP request. Once, every N minutes, daily, weekly.
SSH terminal Ctrl Alt S
Tabbed sessions, SFTP, host key trust, batch execution across hosts. An AI sidebar docks on the right.
Log tail
tail -f on any local file. Realigns when the file rotates or is rewritten in place; pausable, with highlight filters.
Notification center
Monitor outages, scheduled task results and finished AI answers land in one bell. Click through to the monitor or the conversation.
Data directory migration
Move the whole data directory, installed runtimes included, to another drive; environment variables are rewritten. Useful when C: runs out.
Local dev sites
Bind a custom domain to a project and issue an HTTPS certificate automatically. Listens on no port of its own.
WebDAV sync
Full JSON export and restore, versioned snapshots, any WebDAV server.

How versions install

Mirrors are switchable, and the address accepts {version} {os} {arch} placeholders. When one source fails the next is tried, with progress streamed back live.

How services are managed

Start, stop and restart from the list. Save a config and services like Nginx validate before reloading — a syntax error stops there instead of taking down a running service.

Does it touch the system

No registry writes, no changes to system PATH, no admin prompt. Delete the folder and it is gone, with nothing left behind.

04

Configure a model once, use it in four places

The chat page, the SSH sidebar, clipboard entries and the notes window share one model profile.

Models and chat

OpenAI, DeepSeek, Kimi, Qwen, Ollama, Azure, and any compatible endpoint.

  • Enter the base URL and key, then pull that endpoint's model list in one click instead of copying names by hand
  • SSE streaming, with the reasoning trace collapsed by default
  • Math renders through KaTeX, diagrams through Mermaid, code blocks get highlighting; right-click a diagram or formula to copy it as an image
  • Switch to another page while an answer is generating; it keeps going and is waiting where you left it
  • Usage stats cover every entry point, split by model and surface, and are labelled as an estimate rather than a bill
  • API keys are encrypted with Windows DPAPI; the front end never sees the ciphertext

AI in the terminal

The SSH sidebar turns what you're looking at into commands you can run.

  • Select terminal output, right-click, ask — the selection alone becomes the context
  • The screen is attached only when you mention it; otherwise it isn't sent, which saves tokens and avoids misleading the model
  • On production hosts the default is read-only probing; write commands must state their blast radius
  • rm -rf, mkfs and DROP TABLE get a fill-in button only, never a run button
  • Running on production asks twice; fill-in never sends a newline
  • Switching sessions clears the context, so machine A's screen never follows you to machine B

Local capabilities for agents

A built-in MCP server at http://127.0.0.1:9230/mcp.

  • Tools are split into three permission tiers; read-only and low-risk writes are on by default
  • Read-only covers runtime status, project search, todos, notes, clipboard, ports, logs and crash records
  • Low-risk writes start and stop services, open projects, create todos and notes
  • Killing processes and running system commands have to be enabled separately in the runtimes page
  • Starts and stops with the main process; gone when the app quits

DeepSeek Harness

A complete agent coding surface in a native window: tools, files, terminal, sessions.

  • Detects node, npx and dsh and installs whatever is missing, a portable Node included
  • Runs in its own native window; closing the window leaves the service running, and reopening returns to it
  • Fixed port 3080, falling back to a random port only when an unrelated process holds it
  • Every step — download, extract, npm install — is logged

Does it need admin rights?

No. The installer puts the program in %LOCALAPPDATA%\Programs\快启坞, and runtimes and data stay in your user folder — no registry writes, no UAC prompt. For the same reason, installing by hand into C:\Program Files breaks auto-update, because there is no write permission and you'd have to overwrite it manually.

Where is my data, and does it get uploaded?

In ~/.quickdock by default: the database, clipboard images, plugins and logs. Nothing syncs in the background; network requests only happen when you configure WebDAV or call an AI endpoint. If space runs short, move the whole directory to another drive under Settings → Storage & Sync.

Does uninstalling delete my data?

No. Uninstalling removes the program and its registry entry; ~/.quickdock stays. Reinstall and everything is where you left it. Delete the folder yourself once you're sure you don't need it.

Is macOS supported?

Each release ships darwin arm64 and amd64 builds, but development and testing happen on Windows, so coverage on macOS is incomplete — please file an issue if you hit something. There is no Developer ID signature yet, so the first launch has to be allowed in System Settings.
