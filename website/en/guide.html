Guide

From installed to second nature. The first four sections are worth doing in order; the rest are reference. The sidebar jumps anywhere.

01Install

Download quickdock-amd64-installer.exe and run it. No admin rights at any point.

  • It installs to %LOCALAPPDATA%\Programs\快启坞. Afterwards run QuickDock.exe; a tray icon means it's up.
  • Keep the default install path. Auto-update depends on write access to that directory. Put it in C:\Program Files and every update has to clear UAC, which leaves you overwriting by hand.
  • Installing is optional: grab quickdock-amd64.exe and run it as a portable build from a directory your user can write to. In-place updates work there too.
  • The first launch asks once where to keep data. To change it later, go to Settings → Storage & Sync.

02Interface

The main window is three fixed panes, all aligned on one line.

  • Top bar: workspace switcher on the left, scenario tabs in the middle, Config on the right — the runtime services bound to the current scenario hang there.
  • Sidebar: navigation on top (workspaces, notes, todos, schedules, monitors, clipboard, runtimes, AI, DeepSeek Harness, plugins), the scenario list below, a search box between them, and the notification bell plus settings at the bottom.
  • Middle: collections in the current scenario, each with a type icon and an item count.
  • Right: the items of the selected collection. With nothing selected it shows a hint — that's expected, not a bug.
  • The interface scales proportionally under Settings → Preferences. The main window and every detached window zoom together and the proportions stay put.

03Hotkeys

Seven global hotkeys by default. These are the ones you'll reach for all day.

  • CtrlSpace show or hide the main window
  • CtrlK command palette
  • Ctrl` clipboard history
  • CtrlAltN quick notes
  • F1 region screenshot, falling back to CtrlShiftA when it's taken
  • CtrlAltW window tiling overlay, plus 15 more snap hotkeys under Settings → Window Management
  • CtrlAltS SSH terminal
  • All of them can be rebound under Settings → Hotkey Settings, effective immediately, no restart. If you forget one, type cheatsheet in the command palette; the sheet reads your current bindings.

04Resources

Four levels: workspaces hold scenarios, scenarios hold collections, collections hold items.

  • Workspaces separate contexts — Work and Personal, say — so they never interfere.
  • Scenarios are slices of the same resources, with their own tags, icons and colors. Switch to Frontend while writing code, Production while on call.
  • Collections group by purpose and carry one of four open strategies, which decide whether items open all at once or one by one.
  • Items come in six types: folder, file, URL, terminal command, application, shortcut with arguments.
  • Every level can be dragged into order. Commands and URLs accept {date}, {time}, {username} and {clipboard}, expanded at the moment they open.
  • Items can be ticked for batch delete or moved to another collection in the same scenario. An item can carry a mark colour and a custom icon (an image up to 256 KB), plus its own extra arguments.
  • When you can't find something, CtrlK beats digging through the tree.

05Command palette

CtrlK opens it. Type to search, press Enter to run.

  • Results are grouped by source: best match, recent, projects, quick links, notes, todos, applications, files, plugin commands, runtime services, system commands, clipboard suggestions, plus inline calculator and web results.
  • Todos only return unfinished top-level tasks. Enter switches to the todo page, jumps to that day, clears tag filters when needed and highlights the row for two seconds; the action menu can mark it done.
  • Type an expression and the answer appears; paste a URL and it asks whether to save it as a project.
  • Type cheatsheet for the hotkey sheet, or logtail to open log tailing.
  • Two boundaries worth knowing: clipboard history entries aren't searched (the suggestions only cover what you just copied), and each group has a display cap — only recent can be expanded.

06Clipboard

Ctrl` opens the float window, which hides as soon as it loses focus.

  • Text, images and files are all recorded. Images live in ~/.quickdock/images/.
  • Tags come in two kinds: Images, Files, All and Starred filter by type; URL, Email, Phone, JSON and Code are smart categories that only apply to text.
  • Classification is computed and stored when an entry is written, so picking a tag reaches the whole history rather than the 1000 rows the All list loads by default.
  • Ask AI on an entry to translate, summarize or reformat — or ask your own question — answered in place, without leaving the page.
  • Retention is set under Settings → Clipboard, and entries expire on schedule. Automatic rules can clean up what you copy, with a dry run first.
  • History can be cleared in one go, file entries reveal in Explorer, and images save to disk. Rules can be ordered by priority, and you can simulate a source window to see whether they'd match.
  • Every copy in the app goes through the backend system API, unaffected by which window has focus.

07Screenshots

F1 raises a full-screen overlay. Draw a selection and the toolbar appears in place.

  • Six annotation tools: rectangle, ellipse, arrow, line, mosaic, text. Nine colors, four stroke widths, six text sizes.
  • While selecting, hovering a window highlights the whole window and one click takes it; hold Ctrl to drop to the child control.
  • Annotations can be selected, dragged and deleted, text can be double-clicked to edit, and the selection has eight handles.
  • Pin a capture to the screen afterwards: drag it, scroll to scale, double-click to close.
  • Common keys: Enter or CtrlC copies, CtrlS saves, CtrlZ undoes, REALMT switch tools, Esc steps back out.

08Notes

CtrlAltN opens the floating notes window.

  • A tree of notes on the left, folders nest, with search, rename and delete.
  • Content is stored as Markdown and saved 500 ms after you stop typing. There is no save button.
  • The window hides when it loses focus, so it never sits on top of your work.
  • Ask AI in the float: with a selection only that goes, without one the whole note. Presets cover summarize, polish, continue and translate, and you can ask anything. None of it is written to the AI conversation history.
  • The footer counts words, characters and lines, headings become a table of contents you can click through, the tree can be dragged into order, and the whole note exports to .md. An AI answer can go in at the cursor, onto the end, or replace the note.

09Todos

Open Todos from the sidebar; list and kanban views switch freely.

  • Tasks can carry subtasks, tags, notes and an estimate.
  • Repeat rules cover daily, weekly and monthly; finishing one creates the next.
  • A due time triggers a system notification.
  • Pomodoro runs a countdown on the todo page and notifies when it ends; a webhook can push it to your phone under Settings → Robot Notifications.
  • Subtasks can be renamed, moved up or down, and given their own due date; the in-page search filters by title and notes.
  • Search a task title in the command palette and Enter jumps straight to it.

10Monitors

Create one under Site Monitor in the sidebar. An address and an interval is enough.

  • Shows status code, response time and days left on the SSL certificate, and can require a keyword or a regex in the response body.
  • Latency jitter isn't an outage; adjust the threshold in settings so a network hiccup doesn't page you.
  • A state flip pushes a desktop notification, or DingTalk, WeCom, Feishu, ServerChan, PushPlus or Telegram.
  • Trend charts cover 24 hours, 7 days and all time; the monitor list exports to CSV.
  • Every notification also lands in the bell at the bottom of the sidebar, and clicking one jumps to its monitor. AI completion notices stay quiet while the window is in front of you.
  • With many monitors you can search, tick several to enable or disable, and drag them into order. Deleted ones go to a recycle bin and come back with logs and configuration; a one-hour maintenance window pauses checks and alerts.

11Schedules

Five actions and five schedules cover everyday scripts and reminders.

  • Actions: open an application, open a folder, open a URL, run a command, send an HTTP request.
  • Schedules: once, interval, daily, weekly, monthly.
  • Run one immediately from the list instead of waiting for the clock.
  • The list searches by name and filters to failed, enabled or disabled; each row shows how long until the next run. The run history filters to failures and exports to CSV.
  • Bot addresses are configured once under Settings → Robot Notifications; a task only decides whether to send and through which channel.
  • Deleted tasks go to the recycle bin. Restoring recalculates the next run from now, so a task whose time passed long ago doesn't fire the moment it comes back.

12Runtimes

Open Runtimes from the sidebar: groups on the left, versions and services on the right.

  • Install a version by picking it and clicking install; progress streams back live. Switch mirror when one is slow, or point at your own address.
  • Several versions of the same runtime coexist. Switching just moves PATH — nothing is uninstalled or overwritten.
  • Service runtimes — Nginx, MySQL, Redis and the like — start, stop and restart from here. Configs can be edited in the app and reloaded on save.
  • Nginx, Apache and Caddy validate their config before starting; a syntax error stops there instead of breaking a live service.
  • Every service has live logs (last 8 KB) and a web console entry; the port overview shows which process holds which port.
  • Check Project reads the version declarations in a directory — .nvmrc, .tool-versions, go.mod, package.json and more — compares them against what is installed and active, and switches to the missing version on the spot. If Everything returns nothing, the page has a self-test too.
  • Everything installs under %APPDATA%\QuickDock\runtime\: no registry writes, no system PATH changes, no admin rights.

13AI

Start under Settings → AI Assistant: pick a provider, fill in the base URL and key, pull the model list and choose one.

  • Once the profile exists, the chat page, the SSH sidebar, the clipboard's Ask AI and the notes window all share it. You configure it once, not four times.
  • The chat page has multiple sessions, automatic titles and modes (chat, explain code, translate, summarize, tutorial), and your own system prompt can be layered on top.
  • Formulas, diagrams and code blocks render. Diagrams, formulas and code blocks can be copied as images from the context menu, and html blocks open in a full-screen sandbox preview.
  • Switch to another page and the answer keeps generating; come back and it's where you left it.
  • Usage stats sit under Settings → AI Assistant: cost estimates for 7 days, 30 days and all time, split by model and entry point. They're linear estimates from built-in prices, not a bill — your provider's invoice is authoritative.
  • The assistant on the chat page can also do the work: read the project, edit files, run commands. Writes ask first — allow, remember or deny — and pending requests stay pinned above the input box, visible even after scrolling back. "Remember" covers one command family; per-tool overrides live under Settings → AI Assistant.
  • Files are snapshotted before they are edited, so any step can be reverted from the timeline, and the revert itself can be reverted. Works without git too.
  • Plan mode is read-only: it surveys the project and hands you a step-by-step plan before touching anything.
  • Project conventions go in AGENTS.md or .quickdock/rules/*.md instead of being repeated each time; type @ in the composer to pull in a file, a folder or a past conversation.
  • Keys are encrypted with Windows DPAPI; the front end never sees the ciphertext, and deleting a profile deletes it too.

14SSH

CtrlAltS opens a separate window that resizes and minimizes; switching windows doesn't drop the connection.

  • The host tree supports groups (folders), drag reordering, and environment tags: production, staging, test.
  • Authenticate with a password or a key (ed25519 and friends, passphrase supported). Older devices on ssh-rsa need the legacy switch turned on.
  • The first connection to a new machine asks you to confirm its fingerprint. Compare it against ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub on the server before trusting it. Trusted fingerprints are managed in known_hosts on the window's top bar, and a changed fingerprint raises an alert.
  • Several tabs on one host handshake once. Dropped connections reconnect on their own, and scrollback is kept. Reopen the window and last session's tabs come back.
  • A host can be tested for connectivity before you save the form, so you don't keep a config that never connects.
  • The SFTP panel browses remote directories, uploads and downloads, and multi-selects for batch download, move and delete; the path box takes a typed path to jump to.
  • Run Command is one-shot: it runs and disconnects, keeping no session. On production hosts the risk is checked first, high-risk commands can only be filled in, CtrlEnter runs, and output is copyable.
  • Batch execution on a group lets you tick several machines, dry-run first (read-only — it lists the commands and their risks), then run, with output streamed back per host.
  • The AI sidebar on the right: select terminal output, right-click and ask. High-risk commands get a fill-in button only; you press Enter.

15Data & backup

Everything lives in ~/.quickdock by default; configuration is in %APPDATA%\QuickDock.

  • quickdock.db is the main database (workspaces, todos, notes, the clipboard index); images/ holds clipboard images, plugins/ plugins, logs/ logs.
  • Moving: change the storage location under Settings → Storage & Sync. The whole directory is packed and moved to the new drive, taking installed runtimes and environment variables with it, effective after a restart. Leave room on the target for the archive plus the unpacked copy.
  • Cloud sync: configure a WebDAV server on the same page for full JSON backups, keep several versions, restore in one click.
  • Snapshot: export everything to a JSON file and keep it somewhere. Importing overwrites current data — read the prompt first.
  • Uninstalling never deletes data; reinstalling picks it up again.

16Updates & fixes

On startup the app fetches a signed manifest and mentions new versions in settings.

  • Updates replace in place: download the new exe, verify the digest, then after a restart a helper backs up the old one and copies the new one over, rolling back on failure. No UAC, no installer.
  • Most update failures come from installing into a directory without write permission. Use the default path, or download and overwrite manually.
  • When something goes wrong, look under Settings → Logs: main logs by day, filterable by level, with JS and Go crash reports on the same page.
  • Log files can themselves be tailed: type logtail in the command palette, pick a file being written, and only new bytes are read every 500 ms.
  • If a hotkey does nothing, something else probably claimed it. Change it under Settings → Hotkey Settings; it re-registers immediately.
  • If a service won't start, check the validation output on its config page first, then the port overview to see whether another process holds the port.
