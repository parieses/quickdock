01

三栏，装下一天的工作

左边导航，中间集合，右边项目。资源树是四级结构，项目可以是目录、文件、网页、命令、应用，或者带参数的快捷方式。

资源

资源摆在哪，按你的习惯来

工作空间隔离不同项目的上下文，场景是同一份资源的不同切面，集合按用途分组。任何一层都能拖拽排序。

  • 四级结构：工作空间 → 场景 → 集合 → 项目
  • FTS5 全文搜索，中文和英文都能命中
  • 命令与网址支持 {date} {time} {clipboard} 变量，打开时展开
环境

28 种运行时，装在用户目录里

语言、数据库、中间件、网络服务、开发工具，版本想装几个装几个。切换只改一个环境变量，不写注册表，不动系统 PATH。

  • 安装进度逐行推送，下载源可切换、多源回退
  • Nginx、Apache、Caddy 启动前自动跑 *-t 校验
  • 服务日志、Web 控制台、端口总览在同一页
插件

插件跑在沙箱里，权限写在清单上

三种运行时：纯前端、内嵌 JS 沙箱、独立子进程。用到哪些能力就在 plugin.json 里声明，没声明的一律拒绝。

  • 34 个 Host API，涵盖文件、网络、剪贴板、进程、加解密
  • 原生插件在安装期做静态审计，声明与实际调用不一致就告警
  • 官方插件在在线市场里安装和升级
02

顺手带的十几个工具

单独拿出来都不算稀奇，但同在一个窗口、共用一套快捷键，就不用为了截个图或看一眼日志再开一个应用。

命令面板 Ctrl K
项目、笔记、待办、应用、文件、插件命令一起搜，结果按来源分区。粘贴网址会问要不要存成项目。
剪贴板历史 Ctrl `
文本、图片、文件都记账。图片和文件是独立类型，网址、邮箱、JSON、代码在入库时分类，能翻到全部历史。
截图 F1
原生分层窗口做覆盖层，框选、标注、复制、贴图都在同一层里完成，不打开第二个窗口。
窗口排版 Ctrl Alt W
15 个贴屏热键加九宫格浮层，点一格排一次。不占用 Win 加方向键。
快捷笔记 Ctrl Alt N
树形 Markdown 笔记库，自动保存，失焦自动隐藏。浮窗里可以直接问 AI。
待办
列表与看板两种视图，子任务、标签、重复规则、到期提醒，附带番茄专注计时。
网站监控
状态码、响应时间、SSL 到期、关键字匹配。状态翻转时推送到桌面或 Webhook。
定时任务
打开软件、目录、网页，执行命令，发 HTTP 请求。一次性、间隔、每天、每周四种调度。
SSH 终端 Ctrl Alt S
多标签会话、SFTP 文件管理、指纹信任、多主机批量执行。终端右侧可以挂 AI 侧栏。
日志尾随
tail -f 任意本机文件。文件被轮转或原地重写时自动重新对齐，可暂停、可过滤高亮。
通知中心
监控掉线、定时任务结果、AI 回答完成收在一个铃铛里。点通知能跳回对应的监控或那次对话。
数据目录搬家
把整个数据目录连同装好的运行时搬到别的盘，环境变量一起改写。C 盘不够用的时候有用。
本地开发站点
给项目绑自定义域名并自动签发 HTTPS 证书，自身不监听端口。
WebDAV 同步
全量 JSON 导出与恢复，多版本快照，可以指向任意 WebDAV 服务器。

版本怎么装

下载源可以切换，地址里支持 {version} {os} {arch} 占位符。一个源连不上就换下一个，进度实时推回来。

服务怎么管

启动、停止、重启都在列表里点。配置改完保存，Nginx 这类服务先校验再重载，语法错就停在原地，不会把正在跑的服务弄挂。

会不会污染系统

不写注册表，不改系统 PATH，不申请管理员权限。删掉目录就干净了，机器上不留痕。

04

模型配一次，四处都能用

对话页、SSH 终端侧栏、剪贴板条目、笔记浮窗共用同一份模型档案。

模型与对话

OpenAI、DeepSeek、Kimi、通义千问、Ollama、Azure，以及任意兼容接口。

  • 填好地址和 Key 可以一键拉取该接口的模型列表，不用手抄模型名
  • SSE 流式输出，思考过程默认折叠
  • 公式走 KaTeX，流程图走 Mermaid，代码块带高亮；图和公式可以右键复制成图片
  • 切到别的页面，回答继续生成，回来还在原位置
  • 用量统计覆盖全部入口，按模型和场景拆开算，并注明是估算不是账单
  • API Key 用 Windows DPAPI 加密，前端拿不到密文

终端里的 AI

SSH 侧栏把看到的现象转成可以执行的命令。

  • 选中终端输出，右键问 AI，选区单独作为上下文
  • 提到「屏显」才附带当前屏幕，不提就不发，省 token 也不带偏
  • 生产环境默认只给只读探查命令，写入类命令必须写明影响范围
  • rm -rf、mkfs、DROP TABLE 只有「填入」，没有「执行」
  • 生产环境点执行要确认两次，「填入」不会发送回车
  • 切换会话自动清空上下文，A 机器的屏显不会带到 B 机器

对 Agent 开放本地能力

内置 MCP 服务，地址 http://127.0.0.1:9230/mcp。

  • 工具集分三级权限，默认只开放只读与低危写
  • 只读涵盖环境状态、项目检索、待办、笔记、剪贴板、端口、日志、崩溃记录
  • 低危写可以启停服务、打开项目、新建待办与笔记
  • 杀进程和系统命令要单独在环境管理页里开启
  • 随主进程启停，应用退出即失效

DeepSeek Harness

内嵌完整的 Agent 编程入口，工具、文件、终端、会话都有。

  • 自动检测 node、npx、dsh，缺什么装什么，便携 Node 不用自己配
  • 用原生窗口承载，关掉窗口服务继续跑，下次打开直接进
  • 固定 3080 端口，被无关进程占用时才退到随机端口
  • 下载、解压、npm 安装每一步都有日志
05

最近改了什么

按时间倒序，点开看细节。更早的版本在 GitHub Releases 里。

更新不会再卡在下不完，插件没公开的命令 AI 也调不动
  • 应用更新支持断点续传：网络限速、切换镜像、超时中断都不用从 0 重来，进度会落盘，下次接着下。
  • 插件对 AI 公开的命令范围现在说到做到：清单里没声明的命令，AI 就算猜出名字也调不动，会收到一句说明并被告知改用界面操作。插件可以放心把只给界面用的内部命令留在清单外。
  • 时间线每一行标出操作来源：「手动」还是「AI」，排查时不用再猜这条是谁干的。
  • AI 现在能分清「这个工具被关掉了」和「这个应用没有这个功能」：工具清单会同时报开放数、总数与被挡数，需要时会提示你去环境管理页开启，而不是回一句做不到。
  • 插件卡片的介绍固定两行、高度对齐，描述再长也不会把卡片撑得参差不齐；看不全时鼠标悬停有全文。
v0.0.33 2026-10-29 AI 客户端能直接指挥插件，MCP 工具可以逐个关
  • MCP 工具从 33 个加到 35 个：AI 客户端现在能给插件命令传结构化参数（不再只有一段文本）、带参数打开插件界面（纯前端插件也能用），还能回看执行记录。
  • 插件可以在清单里声明自己的命令接受哪些参数：键名、类型、哪些必填，AI 照着填就行。写错的声明只丢这一个字段并记一条日志，不会导致插件装不上。
  • 新增 plugin_exec_logs：AI 跑过哪些插件命令、成功还是失败、用了多久都能查。AI 触发的记录来源标为「MCP」，和手动点击区分开。
  • 环境管理页的 MCP 工具清单按用途分组，可以逐个开关；关掉的工具客户端既看不到也调不动，改完提示需要重启服务或重新握手。
  • SSH 终端的复制粘贴修好了：选中后立刻点复制不再失效，Ctrl+V 不再冒出 ^V，应用内复制的文本也会进剪贴板历史。
  • 定时任务和工作区项目里「打开软件」的目标可以从已安装应用里点选，不必再手打 exe 全路径。
  • 插件窗口声明的尺寸超出屏幕时自动收敛到可用区域，标题栏和右下角不会再被裁掉；插件给 AI 的长系统提示词上限放宽到 24000 字符，超出改为截断而不是让整次调用失败。
  • 删除待办后，侧边栏角标立即更新，不用再等下一轮轮询。
v0.0.32 2026-10-29 DeepSeek Harness 更稳，更新器在国内网络下更可靠，更新说明更好读
  • DeepSeek Harness：修好了窗口里反复「connection lost」一直重连的问题——根因是系统 WebView2 内核过旧（dsh 用到的 Promise.withResolvers / AbortSignal.any 需 ≥119）。现在打开前会先校验 WebView2 版本，过低直接红字提示并拦截打开。
  • dsh 进程意外退出后，已打开的窗口会自动重拉并重导航（带熔断保护），崩溃对用户基本透明；同时修掉了「进程已死却显示运行中」的假存活误判。
  • 安装 / 卸载 / 启动 / 停止都会把进度输出到「环境管理 → DeepSeek Harness」日志面板；卸载改成直接清理目录（不再走 npm uninstall，避免网络不通时卡在「正在卸载」），并加了一键重装。
  • 更新器拉取 manifest 直连 GitHub 失败时也会自动走镜像重试，国内网络下更新检查更稳；更新检查的网络报错提示更全。
  • 更新弹窗与设置弹窗里的「更新说明」从大段纯文本改成要点列表，更易读；无要点时回退原样展示。
  • 数据层放行 openedSceneIds 白名单，支持工作区已打开场景标签页的持久化记忆。
v0.0.31 2026-10-28 SSH 更难用错，监控能找回，环境会告诉你项目缺哪个版本
  • SSH 加了「执行命令」窗口：一条命令跑完就断开，不留会话。生产主机会先核对风险，高危命令只给填入、不给执行，输出可以复制。
  • 主机表单里没保存也能直接测通不通；重开窗口自动恢复上次的标签页；SFTP 支持多选批量下载、移动、删除，路径可以直接输入跳转。
  • 监控可以进回收站，恢复时日志和配置都还在；支持搜索、批量启停、拖拽排序。临时维护能设一小时窗口，期间不检测也不告警。
  • 定时任务加了每月频率、搜索与筛选（仅失败、启用中、已停用）、下次执行倒计时；执行历史能只看失败、导出 CSV。机器人推送收进设置里统一配，不再各页各配一份。
  • 环境管理能按项目目录检查版本要求（.nvmrc、.tool-versions、go.mod、package.json 等），和本机已装、当前激活的版本逐个对比，缺的当场切过去。
  • 笔记加了目录、字数统计、拖拽排序和导出 .md，AI 面板能把结果插入光标、追加到末尾或替换全文。待办支持搜索，子任务可改名、上下移动、单独设截止日。
  • 条目可以设标记颜色和自定义图标，支持批量删除与跨集合移动。剪贴板能批量清空、在资源管理器里定位、把图片另存，自动规则可以排优先级并试跑应用匹配。
  • 底层升到 Wails v3 正式版与 Go 1.26，场景只保留导出。

需要管理员权限吗？

不需要。安装器把程序装到 %LOCALAPPDATA%\Programs\快启坞，运行时和数据都放在用户目录，不写注册表、不弹 UAC。也正因为如此，如果手动把程序装到 C:\Program Files，自动更新会因为没有写权限而失败，只能手动覆盖。

数据存在哪里？会上传吗？

默认在 ~/.quickdock，包括数据库、剪贴板图片、插件和日志。应用不做任何后台同步，只有你主动配置 WebDAV 或调用 AI 接口时才会产生网络请求。空间不够时可以在「设置 → 存储与同步」把整个目录搬到别的盘。

卸载会删掉我的数据吗？

不会。卸载只移除程序和注册表项，~/.quickdock 保留。重装后数据还在原处；确定不需要了再手动删这个目录。

支持 macOS 吗？

每个版本会产出 darwin arm64 与 amd64 两个包，但主力开发和测试都在 Windows 上，macOS 侧的功能覆盖不完整，遇到问题请提 Issue。目前没有 Developer ID 签名，首次打开需要在系统设置里放行。
