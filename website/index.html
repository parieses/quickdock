01

三栏，装下一天的工作

左边导航，中间集合，右边项目。资源树是四级结构，项目可以是目录、文件、网页、命令、应用，或者带参数的快捷方式。

资源

资源摆在哪，按你的习惯来

工作空间隔离不同项目的上下文，场景是同一份资源的不同切面，集合按用途分组。任何一层都能拖拽排序。

  • 四级结构：工作空间 → 场景 → 集合 → 项目
  • FTS5 全文搜索，中文和英文都能命中
  • 命令与网址支持 {date} {time} {clipboard} 变量，打开时展开
环境

29 种运行时，装在用户目录里

语言、数据库、中间件、网络服务、开发工具，版本想装几个装几个。切换只改一个环境变量，不写注册表，不动系统 PATH。

  • 安装进度逐行推送，下载源可切换、多源回退
  • Nginx、Apache、Caddy 启动前自动跑 *-t 校验
  • 服务日志、Web 控制台、端口总览在同一页
插件

插件跑在沙箱里，权限写在清单上

三种运行时：纯前端、内嵌 JS 沙箱、独立子进程。用到哪些能力就在 plugin.json 里声明，没声明的一律拒绝。

  • 34 个 Host API，涵盖文件、网络、剪贴板、进程、加解密
  • 原生插件在安装期做静态审计，声明与实际调用不一致就告警
  • 官方插件在在线市场里安装和升级
02

顺手带的十几个工具

单独拿出来都不算稀奇，但同在一个窗口、共用一套快捷键，就不用为了截个图或看一眼日志再开一个应用。

命令面板 Ctrl K
项目、笔记、待办、应用、文件、插件命令一起搜，结果按来源分区；文件结果可在面板里直接预览。粘贴网址会问要不要存成项目。
剪贴板历史 Ctrl `
文本、图片、文件都记账。图片和文件是独立类型，网址、邮箱、JSON、代码在入库时分类，能翻到全部历史。
截图 F1
原生分层窗口做覆盖层，框选、标注、取色、序号、复制、贴图都在同一层里完成，不打开第二个窗口。
窗口排版 Ctrl Alt W
15 个贴屏热键加九宫格浮层，点一格排一次。不占用 Win 加方向键。
快捷笔记 Ctrl Alt N
树形 Markdown 笔记库，自动保存，失焦自动隐藏。浮窗里可以直接问 AI。
待办
列表与看板两种视图，子任务、标签、重复规则、到期提醒，附带番茄专注计时。
网站监控
HTTP / TCP 端口 / 本机进程 / 自定义命令四种探针，看状态码、响应时间、SSL 到期。状态翻转时推送到桌面或 Webhook。
定时任务
打开软件、目录、网页，执行命令，发 HTTP 请求。一次性、间隔、每天、每周四种调度。
SSH 终端 Ctrl Alt S
多标签会话、SFTP 文件管理、指纹信任、多主机批量执行。终端右侧可以挂 AI 侧栏。
Git 面板
对标 SourceTree：分支 / 标签 / 远端管理，贮藏，文件历史与 blame，amend、cherry-pick、分支对比、side-by-side diff。
文件搜索
接 Everything 的独立检索页：没装给安装引导，装了没起可一键拉起；查询就是 Everything 语法，结果可排序、多选复制路径，右侧直接预览文件。
下载器
aria2 做引擎：链接、磁力、种子与 Metalink 一起管，状态分页、批量操作、七标签详情、速度曲线与磁盘预检；BT、远程引擎和完成通知都在设置里。
日志尾随
tail -f 任意本机文件。文件被轮转或原地重写时自动重新对齐，可暂停、可过滤高亮。
总览
日期条带农历、节气与今日宜忌，加当前城市天气；八张卡收纳最近使用、文件置物架、待办、邮件验证码、端口、常驻服务、Git 与 AI 用量，点哪一条就进哪一条。
通知中心
监控掉线、定时任务结果、邮件验证码、AI 回答完成收在一个铃铛里。点通知能跳回对应的监控、任务或那次对话。
数据目录搬家
把整个数据目录连同装好的运行时搬到别的盘，环境变量一起改写。C 盘不够用的时候有用。
本地开发站点
给项目绑自定义域名并自动签发 HTTPS 证书，自身不监听端口。
WebDAV 同步
全量 JSON 导出与恢复，多版本快照，可以指向任意 WebDAV 服务器。

版本怎么装

下载源可以切换，地址里支持 {version} {os} {arch} 占位符。一个源连不上就换下一个，进度实时推回来。

服务怎么管

启动、停止、重启都在列表里点。配置改完保存，Nginx 这类服务先校验再重载，语法错就停在原地，不会把正在跑的服务弄挂。

会不会污染系统

不写注册表，不改系统 PATH，不申请管理员权限。删掉目录就干净了，机器上不留痕。

04

模型配一次，四处都能用

对话页、SSH 终端侧栏、剪贴板条目、笔记浮窗共用同一份模型档案。

模型与对话

OpenAI、DeepSeek、Kimi、通义千问、Ollama、Azure，以及任意兼容接口。

  • 填好地址和 Key 可以一键拉取该接口的模型列表，不用手抄模型名
  • SSE 流式输出，思考过程默认折叠
  • 公式走 KaTeX，流程图走 Mermaid，代码块带高亮；图和公式可以右键复制成图片
  • 切到别的页面，回答继续生成，回来还在原位置
  • 用量统计覆盖全部入口，按模型和场景拆开算，并注明是估算不是账单
  • API Key 用 Windows DPAPI 加密，前端拿不到密文

终端里的 AI

SSH 侧栏把看到的现象转成可以执行的命令。

  • 选中终端输出，右键问 AI，选区单独作为上下文
  • 提到「屏显」才附带当前屏幕，不提就不发，省 token 也不带偏
  • 生产环境默认只给只读探查命令，写入类命令必须写明影响范围
  • rm -rf、mkfs、DROP TABLE 只有「填入」，没有「执行」
  • 生产环境点执行要确认两次，「填入」不会发送回车
  • 切换会话自动清空上下文，A 机器的屏显不会带到 B 机器

对 Agent 开放本地能力

内置 MCP 服务，地址 http://127.0.0.1:9230/mcp。

  • 工具集分三级权限，默认只开放只读与低危写
  • 只读涵盖环境状态、项目检索、待办、笔记、剪贴板、端口、日志、崩溃记录
  • 低危写可以启停服务、打开项目、新建待办与笔记
  • 杀进程和系统命令要单独在环境管理页里开启
  • 随主进程启停，应用退出即失效

DeepSeek Harness

内嵌完整的 Agent 编程入口，工具、文件、终端、会话都有。

  • 自动检测 node、npx、dsh，缺什么装什么，便携 Node 不用自己配
  • 用原生窗口承载，关掉窗口服务继续跑，下次打开直接进
  • 固定 3080 端口，被无关进程占用时才退到随机端口
  • 下载、解压、npm 安装每一步都有日志
05

最近改了什么

按时间倒序，点开看细节。更早的版本在 GitHub Releases 里。

新增下载器与 MCP 下载工具域，aria2 进环境管理
  • 新增下载器：aria2 作为第 29 个运行时装在「环境管理」里，下载页只管任务。链接、批量链接、磁力、种子、Metalink 都能下；引擎没装或没跑时页面给引导，不会自己悄悄拉一个回来。aria2 1.37 不自带 Web UI，界面是 QuickDock 自己写的，RPC secret 不落到页面里。
  • 界面按成熟 aria2 前端的路子做齐：状态分页、搜索与排序、多选批量与右键菜单、速度曲线与全局统计；详情是七标签弹框（概览 / 文件 / URI / Peers / 服务器 / 选项 / 种子信息），能改 URI、勾选要下的文件、单独调任务选项。
  • 新建下载改成弹框，分链接 / 批量 / 种子 / Metalink 四种模式。高级选项能设请求头、Referer、代理、校验和、上下行限速、做种比例与队列位置；保存前查磁盘剩余空间，低于 1 GiB 先问一句，失败任务在列表、右键和详情里都能重试。
  • BT 参数全接上：DHT / DHT6 / PEX、监听端口、tracker、加密、做种比例，完成后可自动归类与打开文件夹，设置里还能配定时限速。这些参数只在引擎启动时读取，改完要停一次再启动；入站端口 6881–6980 需防火墙放行。
  • 进度刷新改成活跃任务 1 秒一次、等待与已结束每 5 轮补齐，另有 WebSocket 事件（开始 / 暂停 / 完成 / 失败）一到就出快照；WS 在线时轮询降到 3 秒，断线自动退回。完成与失败同时写通知中心并可弹桌面气泡。
  • 修掉「aria2 明明在跑却报超时」：1.37 的成功响应不带 Connection: close，复用被对端关掉的连接会一路卡到 context 超时，现在只读幂等调用关掉 keep-alive 并在网络错误时重试一次。失败任务也删得掉了——已结束的结果要走 removeDownloadResult，删完同步会话，不会被 aria2.session 复活。
  • 设置 → 连接 可指向另一台机器的 aria2（HTTP / HTTPS + 可选 secret）；远程模式下文件落在远端，本机磁盘预检与「打开文件位置」自动跳过。
  • MCP 服务新增「下载器」工具域：7 个工具看引擎状态、任务列表、任务详情、全局统计并暂停 / 恢复 / 删除。download_add 刻意归高危且当前不开放——让宿主向模型给出的任意地址发请求还写盘，是 SSRF 的经典形状。
  • 批量选中从逐个串行调用改成 system.multicall：暂停 / 恢复固定一次往返，删除两次，选几十个不再卡界面；同时补了 4 个测试文件，覆盖启动参数、限速时段、队列位置与 RPC 响应解析。
v0.0.42 2026-11-09 界面重做分层与排版，新增知识库、SSH 跳板，AI 边界与多邮箱精修
  • 界面整体重做了一遍视觉分层：卡片改成「比底亮一档」的纯亮度差，深色下不再叠 1px 描边、内高光和投影，同屏十几张卡也不再发毛；浮层单独提亮一档，下拉盖在卡片上不再像挖了个洞。浅色反过来——白卡片压白底必须留一条边。
  • 排版收口：圆角只剩 4 / 6 / 8 / 12 四档，字号收成七档并清掉 177 处半像素值（10.5、11.5 这类在 100% 缩放下不产生可辨差异，只会让阶梯失真），中文标题不再套「全大写 + 加宽字距」这种给西文准备的写法。
  • 控件统一：按钮只有四档高度（32 / 28 / 24 / 22），三十多个页面各自写过的按钮尺寸全部对齐；勾选框和单选框改成自绘 —— 深色主题下系统会画成一块发白的方块，混在 13px 文字里像贴了张纸；选中态全站统一成「淡底 + 左缘 3px 竖条」，图标不再跟着变蓝。
  • 新增「知识库」：把本地文档（Word / Excel / PDF / Markdown / 文本 / 代码）导进来，中文走 FTS5 trigram 分词，配了 embedding 模型就同时跑向量召回，两路按名次融合；命中给到具体分段，右侧并排显示原文可直接核对。没配模型只走关键词，不会把整库标红。
  • SSH 四项：跳板链（最多三跳，成环会被拦，整条链当一个连接用）、命令片段库、端口转发（本地 / 远程 / SOCKS5，断线按退避重连），以及只有意外断开才触发的自动重连 —— 恢复后会明确提示 vim、sudo 这类前台状态已经丢了。
  • 笔记新增关联图谱（按链接画力导向图，可只看孤立节点）与块级大纲（按标题层级折叠）；专注计时只有已结束的记录落库，可以按篇统计。
  • 图表全部按需重写（柱状 / 折线），配色跟随主题 token。AI 用量改按 token 画 —— 原来「有一天有价就整窗按金额画」会让 Ollama 这类零成本模型的日子变成 0 柱；监控折线修掉时间轴整片落到 1970 的问题。
  • 环境页的项目检查升级为只读体检：版本声明逐条对照本机已装与激活版本，另出一份依赖清单快照；这个页面不会替你执行任何安装命令。
  • 稳定性：浮窗预建改成主窗口就绪事件驱动，修掉启动早期偶发的崩溃；设置红点补齐「崩溃 → 日志分组」的线索。
  • AI 的文件边界收紧：默认只在当前对话的工作目录里读写，越界读取当场弹确认卡、越界写入直接拒绝，报错里的绝对路径也不能把模型带出目录；无人值守的子任务一律拒绝，不再靠一张宽松白名单兜底。
  • 每个会话独立选模型：模型选择移到输入框底部，只影响当前会话并随会话保存；SSH 侧栏、剪贴板、笔记与插件这类没有选择器的入口沿用最后一次选择。
  • 切页不再先白一下：常用页面切走后保留上次内容，切回来先显示旧数据再后台刷新，首次进入给骨架占位。顺带修了 AI 用量卡片的图表样式，提示词编辑改成居中弹框，右侧产物面板加了直接关闭按钮。
  • 邮件验证码支持多邮箱同时收取：账号列表各自独立连接、独立显示状态，旧版单账号配置启动时自动迁移；卡片区分「已连接但没码 / 同步中 / 具体失败原因」，连不上可直接跳各家官方配置教程。
  • 修掉 QQ 邮箱等服务器「凭据没问题却一直连不上」：客户端先等服务器问候再发登录命令，抓取与测试连接都有总时限，响应不回来也不会把后台堵死。
  • 插件独立窗口不再弹 WebView2 原生右键菜单；插件市场与已安装页补了「重新安装」入口。
v0.0.41 2026-11-06 窗口套上 Win11 系统材质，总览加文件置物架与邮件验证码
  • 窗口可以透出 Windows 11 的系统材质了：Mica、Acrylic、Mica Alt 三档，在「设置 → 通用」里选。主窗口、剪贴板 / 命令面板 / 笔记 / 窗口管理四个浮窗、SSH 窗口与插件独立窗口统一跟随同一档；不支持的系统（Win10、关了系统透明效果、高对比度）自动退回实色，界面与加材质之前一致，不会停在「半透明但没材质」的中间态。

需要管理员权限吗？

不需要。安装器把程序装到 %LOCALAPPDATA%\Programs\快启坞，运行时和数据都放在用户目录，不写注册表、不弹 UAC。也正因为如此，如果手动把程序装到 C:\Program Files，自动更新会因为没有写权限而失败，只能手动覆盖。

数据存在哪里？会上传吗？

默认在 ~/.quickdock，包括数据库、剪贴板图片、插件和日志。应用不做任何后台同步，只有你主动配置 WebDAV 或调用 AI 接口时才会产生网络请求。空间不够时可以在「设置 → 存储与同步」把整个目录搬到别的盘。

卸载会删掉我的数据吗？

不会。卸载只移除程序和注册表项，~/.quickdock 保留。重装后数据还在原处；确定不需要了再手动删这个目录。

支持 macOS 吗？

每个版本会产出 darwin arm64 与 amd64 两个包，但主力开发和测试都在 Windows 上，macOS 侧的功能覆盖不完整，遇到问题请提 Issue。目前没有 Developer ID 签名，首次打开需要在系统设置里放行。
