01

三栏，装下一天的工作

左边导航，中间集合，右边项目。资源树是四级结构，项目可以是目录、文件、网页、命令、应用，或者带参数的快捷方式。

资源

资源摆在哪，按你的习惯来

工作空间隔离不同项目的上下文，场景是同一份资源的不同切面，集合按用途分组。任何一层都能拖拽排序。

  • 四级结构：工作空间 → 场景 → 集合 → 项目
  • FTS5 全文搜索，中文和英文都能命中
  • 命令与网址支持 {date} {time} {clipboard} 变量，打开时展开
环境

29 种运行时，装在用户目录里

语言、数据库、中间件、网络服务、开发工具，版本想装几个装几个。切换只改一个环境变量，不写注册表，不动系统 PATH。

  • 安装进度逐行推送，下载源可切换、多源回退
  • Nginx、Apache、Caddy 启动前自动跑 *-t 校验
  • 服务日志、Web 控制台、端口总览在同一页
插件

插件跑在沙箱里，权限写在清单上

三种运行时：纯前端、内嵌 JS 沙箱、独立子进程。用到哪些能力就在 plugin.json 里声明，没声明的一律拒绝。

  • 34 个 Host API，涵盖文件、网络、剪贴板、进程、加解密
  • 原生插件在安装期做静态审计，声明与实际调用不一致就告警
  • 官方插件在在线市场里安装和升级
02

顺手带的十几个工具

单独拿出来都不算稀奇，但同在一个窗口、共用一套快捷键，就不用为了截个图或看一眼日志再开一个应用。

命令面板 Ctrl K
项目、笔记、待办、应用、文件、插件命令一起搜，结果按来源分区；文件结果可在面板里直接预览。粘贴网址会问要不要存成项目。
剪贴板历史 Ctrl `
文本、图片、文件都记账。图片和文件是独立类型，网址、邮箱、JSON、代码在入库时分类，能翻到全部历史。
截图 F1
原生分层窗口做覆盖层，框选、标注、取色、序号、复制、贴图都在同一层里完成，不打开第二个窗口。
窗口排版 Ctrl Alt W
15 个贴屏热键加九宫格浮层，点一格排一次。不占用 Win 加方向键。
快捷笔记 Ctrl Alt N
树形 Markdown 笔记库，自动保存，失焦自动隐藏。浮窗里可以直接问 AI。
待办
列表与看板两种视图，子任务、标签、重复规则、到期提醒，附带番茄专注计时。
网站监控
HTTP / TCP 端口 / 本机进程 / 自定义命令四种探针，看状态码、响应时间、SSL 到期。状态翻转时推送到桌面或 Webhook。
定时任务
打开软件、目录、网页，执行命令，发 HTTP 请求。一次性、间隔、每天、每周四种调度。
SSH 终端 Ctrl Alt S
多标签会话、SFTP 文件管理、指纹信任、多主机批量执行。终端右侧可以挂 AI 侧栏。
Git 面板
对标 SourceTree：分支 / 标签 / 远端管理，贮藏，文件历史与 blame，amend、cherry-pick、分支对比、side-by-side diff。
文件搜索
接 Everything 的独立检索页：没装给安装引导，装了没起可一键拉起；查询就是 Everything 语法，结果可排序、多选复制路径，右侧直接预览文件。
下载器
aria2 做引擎：链接、磁力、种子与 Metalink 一起管，状态分页、批量操作、七标签详情、速度曲线与下载前空间预检；可逐任务指定保存目录、按文件名单独建文件夹，BT、远程引擎、磁盘守卫与换机续传导入都在设置里。
日志尾随
tail -f 任意本机文件。文件被轮转或原地重写时自动重新对齐，可暂停、可过滤高亮。
总览
日期条带农历、节气与今日宜忌，加当前城市天气；八张卡收纳最近使用、文件置物架、待办、邮件验证码、端口、常驻服务、Git 与 AI 用量，点哪一条就进哪一条。城市搜索支持省份、简称与中英文，输省名自动定位省会；邮件卡可点开看原文。
通知中心
监控掉线、定时任务结果、邮件验证码、AI 回答完成收在一个铃铛里。点通知能跳回对应的监控、任务或那次对话。
数据目录搬家
把整个数据目录连同装好的运行时搬到别的盘，环境变量一起改写。C 盘不够用的时候有用。
本地开发站点
给项目绑自定义域名并自动签发 HTTPS 证书，自身不监听端口。
WebDAV 同步
全量 JSON 导出与恢复，多版本快照，可以指向任意 WebDAV 服务器。

04

模型配一次，四处都能用

对话页、SSH 终端侧栏、剪贴板条目、笔记浮窗共用同一份模型档案。

模型与对话

OpenAI、DeepSeek、Kimi、通义千问、Ollama、Azure，以及任意兼容接口。

  • 填好地址和 Key 可以一键拉取该接口的模型列表，不用手抄模型名
  • SSE 流式输出，思考过程默认折叠
  • 公式走 KaTeX，流程图走 Mermaid，代码块带高亮；图和公式可以右键复制成图片
  • 切到别的页面，回答继续生成，回来还在原位置
  • 用量统计覆盖全部入口，按模型和场景拆开算，并注明是估算不是账单
  • API Key 用 Windows DPAPI 加密，前端拿不到密文

终端里的 AI

SSH 侧栏把看到的现象转成可以执行的命令。

  • 选中终端输出，右键问 AI，选区单独作为上下文
  • 提到「屏显」才附带当前屏幕，不提就不发，省 token 也不带偏
  • 生产环境默认只给只读探查命令，写入类命令必须写明影响范围
  • rm -rf、mkfs、DROP TABLE 只有「填入」，没有「执行」
  • 生产环境点执行要确认两次，「填入」不会发送回车
  • 切换会话自动清空上下文，A 机器的屏显不会带到 B 机器

对 Agent 开放本地能力

内置 MCP 服务，地址 http://127.0.0.1:9230/mcp。

  • 工具集分三级权限，默认只开放只读与低危写
  • 只读涵盖环境状态、项目检索、待办、笔记、剪贴板、端口、日志、崩溃记录
  • 低危写可以启停服务、打开项目、新建待办与笔记
  • 杀进程和系统命令要单独在环境管理页里开启
  • 随主进程启停，应用退出即失效

DeepSeek Harness

内嵌完整的 Agent 编程入口，工具、文件、终端、会话都有。

  • 自动检测 node、npx、dsh，缺什么装什么，便携 Node 不用自己配
  • 用原生窗口承载，关掉窗口服务继续跑，下次打开直接进
  • 固定 3080 端口，被无关进程占用时才退到随机端口
  • 下载、解压、npm 安装每一步都有日志
05

最近改了什么

按时间倒序，点开看细节。更早的版本在 GitHub Releases 里。

密码库上线：网页登录自动填充，SSH 密码也有了统一去处
  • 新增密码库：网页登录、SSH、数据库、Git、WebDAV、API Key 一处管理。AES-256-GCM 本地加密，密钥本身再由系统 DPAPI 包裹；只存本机、不随 WebDAV 备份同步 —— 换来的就是密码不离开这台机器。复制密码 30 秒后自动清空剪贴板，锁屏时内存里的密钥同时清零，解锁后自动重建、不用重输。
  • 配 Chrome / Edge 扩展后网页能自动填充：密码框旁浮出建议条，只列与当前域名相关的条目，不会把整个库摊在别人屏幕上；填完 React / Vue 站点也能正常提交。登录后提示「存入密码库」，新密码默认自动保存、改密码仍要确认，按站点分开记录，登录两个不同网站不会互相顶掉。扩展由密码库页面一个开关控制，关掉立刻停止本地监听。
  • SSH 主机可以不填密码了：连接前就地询问，填完存进密码库并记住这台主机，下次直接连；密码改过就重输一次，会同时覆盖主机与库里的旧值。主机表单上也有「从密码库填充」。
  • 笔记预览与代码区终于能划选、能复制：全局禁选（防止误选界面元素）被继承进来，预览区选区根本建立不起来，源码区看着选中了但 Ctrl+C 粘贴出来是空的。顺带重做选中色与活动行底色 —— 活动行此前是不透明色，会把光标那一行的选区整行盖掉，看起来像「选中漏了一行」。
  • 知识库：点过「停止」之后再点重建毫无反应（请求被静默丢弃），现在会自动恢复队列；换了 embedding 模型后语义检索变准 —— 原先把两个不同模型的向量混在一起算相似度，现象是「结果看着正常、只是不准」，比报错难查得多；坏 PDF 也不再能把索引卡死。
  • 下载器与 Git 页的「去安装」现在直接落在对应运行时上。原来跳到环境管理后停在默认选中的 node，还得自己在三十多个运行时里翻。
v0.0.48 2026-11-11 知识库导入 PDF 后搜不到的问题修好了，语义检索可以单配供应商
  • 导入 PDF 后「搜什么都搜不到」修好了：WPS / Word 导出的 PDF 把每个汉字、每个数字都当独立文本块摆放，解析时「间距大于字号就补一个空格」的启发式因此必然误触发，整页中文被插成「项 目 立 项」、「6 0 分」。索引里存的是带空格的串，检索按三字滑窗匹配，于是任何查询都 0 命中——文件本身索引是成功的，坏的是文本。现在汉字、数字、百分号相邻不再插空格（中英文之间的空格保留），已入库的文档点一次重建即可恢复。
  • 检索能听懂多词与整句提问：以前整句被包成一个短语，要求原文逐字连续出现——带空格的多词查询必挂，问答里把整个自然语言问句当检索词更是几乎必然空结果。现在按词切分、中文按三字滑窗取「或」，词与词之间用「且」，全不中时自动放宽为「或」，问「60分以下绩效怎么发」也能召回对应段落。
  • 「60分」「80分」「70%」这类数字加中文的混合词以前会被按中英文切碎、每段都不足三字而整词丢弃，查询变成空串，现在整词兜底。
  • 知识库设置终于真的生效了：app_state 的键白名单漏了 kb_settings，保存直接报 invalid app_state key、读取静默回退默认值，于是设置页填的语义检索模型从来没被用上，重建索引也不走向量，还不留错误痕迹。
  • 语义检索可以单独配供应商：embedding 支持独立的接口地址与密钥，留空仍沿用当前 AI 档案。DeepSeek 和不少中转站只提供聊天、没有 /embeddings 端点，现在单独填一家（如硅基流动的 BAAI/bge-m3）即可，密钥读写全程掩码。
  • 配好 embedding 后，问答从纯关键词升级为「关键词 + 语义」双路召回并按 RRF 融合，口语化提问的命中率明显提升。
v0.0.47 2026-11-11 邮件能看原文、环境管理有「?」资料卡，顺手收掉一批卡手的小问题
  • 邮件验证码能点开看原文了：HTML 正文按卡片样式渲染，不加载外链、不执行脚本；MaxMind 两种安全告警模板也能识别，密码变更 / 异地登录类邮件单独标注并推通知中心。多账号模板兼容与连接失败提示一并收拾。
  • 环境管理每个运行时标题旁的「?」从一句话扩成一张资料卡：分组、本页能做什么、首次上手提示、实时状态（已装版本 / 受管服务 / 常驻开关 / 控制台端口）与官网 / 文档 / 源码链接。浮层按真实高度决定往上还是往下弹，内容过长自己滚动。
  • 天气城市搜索不再冒出一堆同名村镇：以前输「河南」会返回黑龙江 / 浙江 / 北京 / 朝鲜 / 四川那些恰好叫「河南」的村街，现在省名、简称与中英文输入都自动定位到省会，结果按人口与行政级别筛选，机场、村庄和同点多语言别名都不再混进备选；「海口」「台北」这类中文索引不全的城市也一并修好。
  • AI 助手的思考过程与工具调用统一默认收起，流式期间也一样：摘要行给实时字数 / 调用数当进度，点开才铺开内容，长推理与五六个工具调用不会把正文挤出屏幕。
  • 修掉「点任何导航，整块内容区全空」：总览页模板曾变成 fragment 根，与内容区的 out-in 切换动画相撞，离场钩子不回调、占位注释一直留着。现在弹窗回到单根内部，注册页也写明了内容页必须单根的约束。
  • 「使用说明」入口补齐：设置 → 关于与工作空间的空状态引导都放了教程地址，地址在代码里只写一份，两处共用。
  • 稳定性：aria2 保存目录指向已拔掉的移动硬盘不再让启动无限自愈，便携 / 系统同一份不再显示成两个已安装版本；剪贴板探测失败日志收敛、命令面板 FTS5 查询、SFTP 权限弹窗、笔记与下载设置几处交互也一并修了。
v0.0.46 2026-11-10 启动密码锁，浮窗唤出不再闪白
  • 启动密码锁：离开座位时把界面锁上。主窗口与所有独立窗口都只剩一个解锁框，浮窗热键改成唤出主窗口并弹一句提示；后台照常跑——监控轮询、定时任务、邮件取码、天气、剪贴板监听、SSH 会话、MCP 监听都不受影响。锁定期间 MCP 工具调用整体拒绝（把全库交给本机任意进程等于没锁），窗口排版 Ctrl+Alt+W 与截图 F1 放行。
  • 密码本身：bcrypt 哈希再经 DPAPI 加密后存 app_state，这张表不进 WebDAV 备份，所以密码不会跟着同步走（换机恢复后需要重设）。设密码时给一份一次性恢复码，只显示一次、库里只留哈希，忘了密码就用它清空重设。连续输错 5 次开始退避，时长逐次翻倍、上限 5 分钟，计时在后端。
  • 输满自动解锁：设 / 改密码时记下长度，解锁时输到该长度就直接校验，不必再按回车。长度按字符计，含 emoji 的密码也对得上；输入法组合期间不判长度，避免拼音中途撞长度抢在选字前提交。之前设过密码的用户第一次成功解锁时会自动补记，从下次锁定起生效。
  • 浮窗唤出那一帧白闪修掉了：Wails 隐藏窗口时会连 WebView2 控制器一起设成不可见，控制器据此释放 GPU surface，再显示时第一帧是空的——这帧画在 WebView2 子窗口内部、压在我们的客户区之上，调窗口底色和 DWM 材质都盖不住（深浅色主题下闪的都是同一个纯白）。现在改成显示前先把窗口挪到屏幕外，60ms 后移回目标位置，重连照常发生但落在看不见的地方；顺带把材质补写从「一次唤起连改两次」压成一次。
  • 几处性能收紧：笔记面板的 CodeMirror 内核改为按需加载，主窗口首屏省下约 300KB；日志尾读加 8MB 预算并去掉 O(n²) 前插，几百 MB 的运行时日志不再整份读进内存；app_state 读加进程内缓存，剪贴板每次复制少三次数据库往返；总览热力格与两处搜索高亮提进缓存，页面任何状态变化不再触发全量重算。

需要管理员权限吗？

不需要。安装器把程序装到 %LOCALAPPDATA%\Programs\快启坞，运行时和数据都放在用户目录，不写注册表、不弹 UAC。也正因为如此，如果手动把程序装到 C:\Program Files，自动更新会因为没有写权限而失败，只能手动覆盖。

数据存在哪里？会上传吗？

默认在 ~/.quickdock，包括数据库、剪贴板图片、插件和日志。应用不做任何后台同步，只有你主动配置 WebDAV 或调用 AI 接口时才会产生网络请求。空间不够时可以在「设置 → 存储与同步」把整个目录搬到别的盘。

卸载会删掉我的数据吗？

不会。卸载只移除程序和注册表项，~/.quickdock 保留。重装后数据还在原处；确定不需要了再手动删这个目录。

支持 macOS 吗？

每个版本会产出 darwin arm64 与 amd64 两个包，但主力开发和测试都在 Windows 上，macOS 侧的功能覆盖不完整，遇到问题请提 Issue。目前没有 Developer ID 签名，首次打开需要在系统设置里放行。
