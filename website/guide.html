使用说明

从装好到用顺手。前四节是必须走一遍的，后面按需翻。左侧目录可以直接跳。

01安装

下载 quickdock-amd64-installer.exe 双击安装即可，全程不需要管理员权限。

  • 默认装到 %LOCALAPPDATA%\Programs\快启坞，装完运行 QuickDock.exe，托盘出现图标即可。
  • 安装路径建议保持默认。自动更新依赖对安装目录的写权限，装到 C:\Program Files 之后每次更新都要过 UAC，就只能手动覆盖。
  • 不想装也行：直接下 quickdock-amd64.exe 当便携版用，放在当前用户可写的目录，同样支持就地更新。
  • 首次启动会问一次数据目录放哪，之后不再问。想改的话到「设置 → 存储与同步」。

02界面

主窗口固定三栏，从上到下一条线对齐。

  • 顶栏：左边切工作空间，中间是场景标签页，右边是「配置」——当前场景绑定的环境服务在这里挂。
  • 侧栏：上半是导航（工作空间、笔记、待办、定时、监控、剪贴板、环境管理、AI、DeepSeek Harness、插件），下半是场景列表，中间有搜索框，底部是通知铃铛和设置。
  • 中栏：当前场景下的集合，每个集合带类型图标和项目数量。
  • 右栏：选中集合里的项目。没选集合时这里显示提示，不是坏了。
  • 整体界面可以在「设置 → 通用」里等比缩放，主界面和所有独立窗口一起放大，布局比例不变。

03快捷键

默认七个全局热键，记住这几个就够用一整天。

  • CtrlSpace 显示或隐藏主窗口
  • CtrlK 命令面板
  • Ctrl` 剪贴板历史浮窗
  • CtrlAltN 快捷笔记
  • F1 区域截图，被占用时回退 CtrlShiftA
  • CtrlAltW 窗口排版浮层，另有 15 个贴屏热键在「设置 → 窗口管理」
  • CtrlAltS SSH 远程终端
  • 全部可在「设置 → 快捷键设置」里改，改完立即生效，不用重启。忘了按什么就在命令面板里输入 cheatsheet，弹出的表读的是你当前的键位。

04资源管理

四层结构：工作空间装场景，场景装集合，集合装项目。

  • 工作空间用来隔离上下文，比如「公司」和「个人」各一个，互不干扰。
  • 场景是同一份资源的不同切面，可以带标签、图标和颜色。写前端时切到「前端」，运维时切到「线上」。
  • 集合按用途分组，有四种打开策略，决定项目是一次性全打开还是逐个点。
  • 项目有六种类型：目录、文件、网页、终端命令、应用、带参快速链接。
  • 任意层都能拖拽排序。命令和网址里可以写 {date}、{time}、{username}、{clipboard}，打开的那一刻才展开成实际值。
  • 项目列表可以勾选，批量删除或移到当前场景的其它集合。条目能设标记颜色和自定义图标（256 KB 内的图片），也能单独给附加参数。
  • 找不到东西时按 CtrlK 搜，比在树里翻快。

05命令面板

CtrlK 打开，输入即搜，回车执行。

  • 结果按来源分区：最佳匹配、最近、项目、快速链接、笔记、待办、应用程序、文件、插件命令、环境服务、系统命令、剪贴板建议，另有计算器和网页两组就地结果。
  • 搜索待办时只列没完成的顶层任务。回车会切到待办页、跳到那一天、必要时清掉标签过滤，目标行高亮两秒；动作菜单里能直接标记完成。
  • 输入算式直接出结果，粘贴网址会问你要不要存成项目。
  • 输入 cheatsheet 看快捷键表，输入 logtail 打开日志尾随。
  • 两个边界：剪贴板历史条目不参与搜索（面板里的建议只针对刚复制的那一条）；各区有显示上限，只有「最近」能展开。

06剪贴板

Ctrl` 唤出浮窗，失焦自动隐藏。

  • 文本、图片、文件都会记录。图片存在 ~/.quickdock/images/。
  • 标签分两类：图片、文件、全部、已收藏 按类型筛；网址、邮箱、电话、JSON、代码 是智能分类，只作用于文本条目。
  • 分类在入库时算好存进数据库，所以切到某个标签能翻到全部历史，不受「全部」列表默认载入 1000 条的限制。
  • 条目上可以「问 AI」：翻译、摘要、格式化，或者自己提问，回答就地弹出，不跳页。
  • 保留天数在「设置 → 剪贴板」里配，到期自动清理。可以设自动规则清洗复制进来的内容，改之前能先试运行。
  • 条目多了能一键清空，文件条目可以直接在资源管理器里定位，图片能另存。自动规则能排优先级，也能模拟来源窗口试一下会不会命中。
  • 全应用的复制都走后端系统 API，不受窗口焦点影响。

07截图与贴图

F1 进入全屏覆盖层，框选之后原地浮出工具条。

  • 六种标注：矩形、椭圆、箭头、直线、马赛克、文字。颜色 9 种、线宽 4 档、字号 6 档。
  • 框选时把光标移到窗口上会高亮整个窗口，单击直接选中；按住 Ctrl 下沉到子控件。
  • 标注画错了可以点选、拖动、删掉。文字双击能重新编辑。选框有 8 个控制点。
  • 截完可以直接贴图钉在屏幕上，能拖、能滚轮缩放、双击关闭。
  • 常用键：Enter 或 CtrlC 复制，CtrlS 保存，CtrlZ 撤销，REALMT 切工具，Esc 逐层退出。

08笔记

CtrlAltN 打开浮动笔记窗口。

  • 左侧是树形笔记库，文件夹可以嵌套，支持搜索、重命名、删除。
  • 内容按 Markdown 保存，停下 500ms 自动存盘，没有保存按钮。
  • 窗口失焦自动隐藏，不会挡着底下的东西。
  • 浮窗里的「问 AI」：有选区只送选中的那段，没有就送整篇。预置总结、润色、续写、翻译，也能自由追问，整个过程不写入 AI 对话历史。
  • 底部显示字数、字符数和行数，标题会生成目录，点一下跳到那一节。左侧笔记可以拖拽排序，整篇能导出成 .md。AI 的回答可以插入光标、追加到末尾或直接替换全文。

09待办

侧栏「待办任务」进入，列表和看板两种视图随时切。

  • 任务可以带子任务、标签、备注、预计时长。
  • 重复规则支持每日、每周、每月，勾上之后到期自动生成下一条。
  • 设了到期时间会在系统通知里提醒。
  • 番茄专注在待办页启动倒计时，结束后发系统通知，也可以在「设置 → 机器人通知」里配 Webhook 推到手机。
  • 子任务能改名、上下移动、单独设截止日；页内搜索按标题和备注过滤。
  • 在命令面板里搜任务标题，回车能直接跳到那一条。

10监控与通知

侧栏「网站监控」新建一条，填地址和探测间隔就行。

  • 能看状态码、响应时间、SSL 证书剩余天数，还能要求响应体里必须出现某个关键字或匹配某条正则。
  • 延迟抖动和真正宕机是两回事，可以在设置里调判定阈值，避免网络抖一下就报警。
  • 状态翻转时推送到桌面通知，也能配钉钉、企业微信、飞书、Server酱、PushPlus 或 Telegram。
  • 趋势图有 24 小时、7 天、全部三个区间，监控列表能导出 CSV。
  • 所有通知最后都会收进侧栏底部的铃铛，点一条直接跳回对应的监控。窗口正开着的时候 AI 完成通知不会打扰你。
  • 监控多了可以搜索、勾选批量启停、拖拽排序。删掉的进回收站，恢复时日志和配置都在；临时维护能设一小时窗口，期间不检测也不告警。

11定时任务

五种动作配五种调度，够覆盖日常的脚本和提醒。

  • 动作：打开软件、打开目录、打开网页、执行命令、发 HTTP 请求。
  • 调度：一次性、按间隔、每天、每周、每月。
  • 列表里可以手动「立即执行」一次，不用等到点。
  • 列表能按名称搜，也能只看失败的、启用中的或已停用的；每条都显示下次执行还有多久。执行历史里能只看失败、导出 CSV。
  • 机器人推送地址在「设置 → 机器人通知」里配一次，任务里只管发不发、走哪个渠道。
  • 删掉的任务会进回收站。恢复时按当前时间重算下次运行，不会因为原定时间早就过了而立刻补跑一次。

12环境管理

侧栏「环境管理」，左边按分组列运行时，右边是版本与服务。

  • 装新版本：选版本号点安装，进度会实时推回来。一个下载源慢就换一个，也可以配自己的镜像地址。
  • 同一个运行时可以共存多个版本，切换只是把 PATH 指过去，不卸载也不覆盖。
  • 服务型运行时（Nginx、MySQL、Redis 这类）支持启动、停止、重启，配置能直接在应用里改，保存后按需重载。
  • Nginx、Apache、Caddy 在启动前会跑一遍配置校验，语法错就停住，不会把线上服务弄挂。
  • 每个服务都有实时日志（尾部 8KB）和 Web 控制台入口；端口总览能看到谁占了哪个端口。
  • 「检查项目」会读目录里的 .nvmrc、.tool-versions、go.mod、package.json 等版本声明，和本机已装、当前激活的版本逐个对比，缺的当场切过去。Everything 搜不到文件时，页内还有个自测入口。
  • 所有东西装在 %APPDATA%\QuickDock\runtime\ 下，不写注册表，不改系统 PATH，不需要管理员权限。

13AI 助手

先到「设置 → AI 助手」建一个档案：选服务商，填 BaseURL 和 Key，点「拉取模型列表」挑一个模型。

  • 档案建好之后，对话页、SSH 终端侧栏、剪贴板条目的「问 AI」、笔记浮窗共用同一份，不用配四遍。
  • 对话页支持多会话、自动起标题、切模式（聊天、解释代码、翻译、总结、使用教程），也能叠加自己的 System Prompt。
  • 回答里的公式、流程图、代码块都会渲染。图、公式、代码块可以右键「复制为图片」，html 代码块能开全屏沙箱预览。
  • 切到别的页面，回答会继续生成，回来还在原位置。
  • 「设置 → AI 助手」里有用量统计：近 7 天、30 天、全部的花费估算，按模型和入口拆开。按内置单价线性算，不是账单，以服务商结算为准。
  • Key 用 Windows DPAPI 加密存储，前端拿不到密文。删掉档案时密文一并删除。

14SSH 终端

CtrlAltS 打开独立窗口，可以缩放、最小化，切换窗口不断连。

  • 左侧主机树支持分组（文件夹），可以拖拽排序，给主机打环境标签：生产、预发、测试。
  • 认证用密码或私钥（ed25519 等，可带口令）。老设备用 ssh-rsa 的话要打开 legacy 开关。
  • 第一次连一台新机器会弹出指纹确认，拿它跟服务器上 ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub 的输出对一下再信任。已信任的指纹在窗口顶栏的 known_hosts 里管理，指纹变了会主动告警。
  • 同一个主机开多个标签只握手一次。断线会自动重连，滚动回放还在。关掉窗口再打开，上次的标签页会自己回来。
  • 主机表单没保存也能先测连通性，省得存一个连不上的配置。
  • SFTP 面板能浏览远程目录、上传下载，也能多选批量下载、移动、删除；路径框可以直接输入跳转。
  • 「执行命令」是一次性的：跑完就断开，不留会话。生产主机会先核对风险，高危命令只给填入不给执行，CtrlEnter 直接跑，输出能复制。
  • 在分组上「批量执行」可以勾多台机器，先预演（只读，列出将执行的命令和风险）再运行，逐台回传输出。
  • 右侧 AI 侧栏：选中终端输出右键就能问，高危命令只给「填入」，你自己按回车。

15数据与备份

默认所有数据都在 ~/.quickdock，配置文件在 %APPDATA%\QuickDock。

  • quickdock.db 是主库（工作空间、待办、笔记、剪贴板索引），images/ 放剪贴板图片，plugins/ 放插件，logs/ 放日志。
  • 搬家：在「设置 → 存储与同步」改存储位置。整个目录打包搬到新盘，装好的运行时和环境变量一起带走，重启生效。目标盘要留出压缩包加解压的峰值空间。
  • 云同步：同一个页面配 WebDAV 服务器，做全量 JSON 备份，保留多个版本，能一键恢复。
  • 快照：一键把全部数据导出成 JSON 文件，随手存一份。导入会覆盖当前数据，做之前先看一眼提示。
  • 卸载不会删数据，重装后还能接上。

16更新与排错

应用启动后会拉取签名清单，有新版就在设置里提示。

  • 更新是就地替换：下载新 exe，校验摘要，重启后由 helper 备份旧的、覆盖新的，失败会回滚。不弹 UAC，也不跑安装器。
  • 更新失败大多是装到了没有写权限的目录。换成默认路径，或者手动下载新版本覆盖。
  • 出问题先看「设置 → 日志」：按天列主日志，可以按级别过滤，同页还能看 JS 和 Go 的崩溃现场。
  • 日志文件本身也能尾随：命令面板输入 logtail，选一个正在被写入的文件，每 500ms 只读新增部分。
  • 热键没反应，多半是被别的软件占了。到「设置 → 快捷键设置」换一个，改完立即重注册。
  • 服务起不来，先在配置页看校验输出；再看端口总览，是不是端口被别的进程占了。
